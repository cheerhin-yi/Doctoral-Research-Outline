## 5. 读法

1. **VisDrone：每个密度箱的 small recall 最佳都是 UnifAll**（10 个非零箱全部如此），F1280 次之，DensK1 第三；F1280 − DensK1 在每个箱都为正且 CI 不含 0，总体随密度增大但不单调：valid_gt 各箱 +0.035／+0.022／+0.037／+0.038／+0.046；small_gt 各非零箱 +0.030／+0.037／+0.027／+0.043／+0.045。UnifAll 的代价是 precision 比 F1280 低 0.13–0.22，时延约为 F1280 的 3.1–3.5×（1660）／5.0–5.3×（5060 Ti）。
2. **DensK1 与 F1280 的时延差随密度变化，且依 GPU 而异：** 1660 上从稀疏箱的 −1.20 ms（F1280 更快）变为最密箱的 +0.78／+0.95 ms（F1280 更慢；密集图检测框多，整图 1280 的后处理更重）；5060 Ti 上各箱都在 −13.6 至 −14.4 ms（F1280 更快）。
3. **UAVDT：协议排序随密度翻转。** 最稀的非零箱（valid_gt 1–9，9522 帧／25 序列）small recall 最佳是 UnifAll（0.812），F1280 与 DensK1 无差别（Δ −0.0009 [−0.0270, +0.0271]），F1280 − UnifAll −0.015 [−0.039, +0.006] 不显著；valid_gt ≥ 10 的四个箱最佳都是 F1280，F1280 − DensK1 为 +0.018 → +0.032（CI 都在 0 以上）。按 small_gt 分箱时 F1280 在每个非零箱最佳，F1280 − DensK1 在前三箱 CI 擦过 0（下界 −0.0004、−0.0001、−0.0023），在 small_gt ≥ 12 的两箱显著为正。
4. **DensK1 从未在任何箱成为 small recall 最佳**；它相对 F1280 的劣势在最稀疏的 UAVDT 帧上消失，在密集场景最大——单窗只能覆盖一个密集区域，目标越多，窗外遗漏越多（参见 Run J 失败例 1–2）。
5. 最密箱（VisDrone valid_gt ≥ 64，UAVDT valid_gt ≥ 28）所有协议的 small recall 都显著下降（VisDrone F1280 0.357，UAVDT 0.727），协议间差距只有几个百分点——密度本身是主要难度来源。

## 7. 对 C2（如何选协议）的含义

协议选择应以**场景密度**为条件：在 VisDrone 各密度箱和 UAVDT 中高密度帧上，F1280 比 DensK1 准，且差距总体随密度扩大；DensK1 只在 UAVDT 最稀疏帧上与 F1280 打平，从未领先。追求最高 small recall 且能承受 precision 下降和多倍时延时选 UnifAll（VisDrone 各箱、UAVDT 最稀疏帧）。单窗选择性推理（DensK1）在本冻结设置下没有找到占优的密度区间。时延比较须带 GPU：DensK1 与 F1280 的时延差在 1660 上随密度从 −1.2 变到 +0.9 ms，在 5060 Ti 上恒为约 −14 ms（F1280 更快）。
