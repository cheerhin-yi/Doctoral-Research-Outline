# P0_EI Related Work 对照矩阵（写作骨架）

> 只保留与「冻结权重 + 推理协议」相关的近邻。详细审计原文在 `notes/`。

| 近邻工作                     | 族     | 与本篇相同点      | 与本篇不同点（主张缺口）        | 本篇可写的对照句              |
| ------------------------ | ----- | ----------- | ------------------- | --------------------- |
| SAHI (W-0002)            | 切片推理  | 切片抬小目标可见性   | 常配合微调；非五协议系统对比+配对统计 | 采用同族切片轴，比较协议而非提出 SAHI |
| QueryDet (W-0003)        | 高分辨加速 | 关心高分辨率小目标代价 | 改网络查询机制；需训练         | 本篇不改网络，只改推理协议         |
| ESOD (W-0004)            | 高效小目标 | 高分辨率图像上的效率  | 方法/训练向              | 对照「效率叙事」，本篇用墙钟与超时     |
| ROI-Gated SAHI (W-0005)  | 自适应切片 | 密度/ROI 引导切片 | 门控模块与训练设定不同         | DensK1 为协议层密度片，非新门控网络 |
| Dynamic Zoom-in (W-0008) | 多阶段放大 | 局部高分辨       | 级联策略与训练             | 本篇单检测器多协议，无级联训练       |
| AutoFocus (W-0009)       | 多尺度推理 | 多尺度推理预算     | 经典多尺度金字塔设定          | 对照多尺度预算，强调冻结权重        |

**明确不进入本矩阵（已归档）：** 铁路异物专用数据叙事、低分候选机制、弱响应头、ViCrop-Det HOLD 评审等。
