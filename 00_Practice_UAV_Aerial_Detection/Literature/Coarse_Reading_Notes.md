# 粗读学习笔记（主题级）

用途：一周内建立「本课题文献地图」，不替代各篇 `notes/`。  
主张口令（写摘要／Intro 前先念）：**协议族对照实验**；同一 `last.pt`、同一后处理；只改怎么推；负结果也进贡献边界。

## T1 切片推理

- 核心操作：切 → 检 → 映射回原图 → NMS／聚合。
- 代价轴：切片数、重叠、额外前向、墙钟；精度轴：小目标召回与整体 AP。
- 写 Related Work 时归「推理时增强／切片评测」，不要写成又一个检测器。

## T2 高分辨／高效

- QueryDet／ESOD 一类多是**改网络或训练**换效率。
- 本篇用它们只为划界：读者一眼看到「问题=协议选择」，不是「又涨了几个点的新模块」。

## T3 多尺度／放大

- Dynamic Zoom-in／AutoFocus／ClusDet：学问题起笔与方法图版式。
- 读表时盯：有没有把**时延**和**前向次数**写清；缺的就是正文要补的列。

## T4 航拍评测

- VisDrone：主精度与配对统计（D／F）。
- UAVDT：跨集；排序若不稳，写入贡献边界（仅数据集内／不稳），审稿更信。
- 1660 与 4090 **分表**，禁止混硬件报一条 FPS。

## 练笔目标（第一周）

一页半：摘要（系统比较并量化…）+ 一张配对差主表骨架 + 一段负结果。  
每读一篇只抽三样落笔记（见模板）；笔记进主题 `notes/`，不要堆回 Literature 根目录。
