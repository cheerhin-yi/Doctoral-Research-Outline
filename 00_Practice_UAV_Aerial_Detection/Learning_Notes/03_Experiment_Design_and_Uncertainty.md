## 第一部分：必须掌握

### 学习目标

1. 能把一句论文主张改写成**可证伪假设**（含固定因素、唯一变量、失败条件）。
2. 能填一张完整实验卡，并说明为何「只给新方法调参」不公平。
3. 能区分：开发集证据、一次性终评、图级配对推断；知道哪类数字能进 EI 稿主表。

### 知识链

```text
主张（C1/C2）
→ 可证伪假设
→ 固定因素清单（权重/阈值/conf/IoU/小目标定义/硬件）
→ 唯一对照变量（五方法之一）
→ 评价单元（图，不是框）
→ 停止条件与负结果
→ 不确定度（CI / 配对检验）与披露
```

### 链上要点（教材）

1. **主张 ≠ 算法创新。** P0 当前只比较已冻结的推理协议：`F640` / `F1280` / `DensK1` / `UnifAll` / `SAHI640`。不得把结果写成「提出了新检测头」。
2. **固定因素必须先锁。** 至少写清：权重 SHA、conf、IoU、小目标面积阈值、数据集 split、是否允许看 test-dev 调参。Stage D/F 已按「一次性终评」纪律执行。
3. **评价单元。** 主结论若声称「方法 A 优于 B」，统计单元必须是**图像**；框级堆叠会虚高自由度。Stage F 已按图级 Wilcoxon + 配对 bootstrap。
4. **开发 vs 终评。** cal48 / 诊断集只能支撑流程与方向；test-dev 终评与配对 CI 才支撑主表措辞。混表硬件（1660SUPER 与 4090）必须分列。
5. **负结果是资产。** 超时率上升、精度换召回、CI 跨 0，都应进稿或附录，不得静默删除。

### 练习

1. 为 `P0-EI-C1`（F1280 相对 DensK1 在小目标召回上更优且不显著更慢）写一张实验卡：主张、假设、固定因素、唯一变量、主指标、副指标、停止条件。
2. 指出一个「伪对照」：例如 DensK1 用更高 conf、F1280 用更低 conf。说明它破坏了哪条链。
3. 给定：图级 Δrecall_small 的 95% CI 为 [0.035, 0.046] 且不过 0；写一句**允许**出现在论文里的表述，再写一句**禁止**的过度表述。

### 必答题

1. 为什么 P0 主统计不能把所有框当成独立样本？
2. 「median-of-3 计时」和「Stage D 单次 total_ms」分别适合回答什么问题？混用会怎样误导 C1？
3. 若 Stage E（UAVDT）未就绪，EI 稿主主张可否仅依赖 VisDrone test-dev？需要披露什么？
