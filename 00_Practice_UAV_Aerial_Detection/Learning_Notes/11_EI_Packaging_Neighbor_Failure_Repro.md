## 第一部分：必须掌握

### 学习目标

1. 能按 EI 会议短文结构，说出 **四块最小增量** 各回答什么审稿问题。
2. 能设计 **近邻协议对照表**（neighbor-protocol table）：比的是相邻协议轴，不是刷榜总表。
3. 能挑选并描述 **失败 / 边界例**（漏检主导、误检主导、切片接缝、映射后类别空洞），且不把个例写成全称命题。
4. 能列出 **可复现附录** 必填项，并区分 1660SUPER 流水线时序 vs 4090 正式时序。

### 知识链

```text
已冻结证据（A–F；E 外推）
→ 主张句定稿（允许 / 禁止）
→ 近邻协议表（单一轴差分）
→ 跨集厚写（一致趋势 + 名次不稳）
→ 失败 / 边界例（定性，服务讨论）
→ 可复现附录（权重 SHA、映射、配置、评价器、硬件分列）
→ （可选）4090 正式时序表单独成表
→ 停笔检查：无新训、无改映射、无通论排序
```

### EI 稿推荐骨架（与实验增量一一对应）

| 章节 | 最小增量 | 读者要被说服的点 |
|---|---|---|
| Intro / Contribution | 主张 C1/C2 + 非算法声明 | 这是协议论文 |
| Related Work | 多分辨率 / tiling / SAHI 族；训练期小目标法作对照 | 位置诚实 |
| Method | 五协议定义 + 冻结权重 + 映射（若跨集） | 可复现操作 |
| Experiments | D 主表 + F 配对 + E 外推；近邻表 | 证据链完整 |
| Discussion | 跨集名次不稳、失败例 | 边界清楚 |
| Appendix | SHA、配置、评价器、硬件 | 可复核 |

### 近邻协议表（写法纪律）

**目的：** 展示「只动一个协议旋钮」时的精度–召回–代价移动，而不是五列大满贯夺冠叙事。

推荐至少三类近邻对（数字以已冻结 Run 为准，学习时只练表头与句子）：

1. **分辨率轴：** F640 ↔ F1280  
2. **选区轴：** DensK1 ↔ UnifAll（局部加精 vs 全覆盖）  
3. **工程切片轴：** SAHI640 ↔ UnifAll 或 SAHI640 ↔ F1280（切片族 vs 整图高分辨）

表列建议：`pair`、`Δsmall_recall`、`Δprecision`（或协议定义的精度列）、`Δtime` 或超时、`同机`、`数据集`。  
跨集：VisDrone 与 UAVDT **分表或分面**，禁止一行混集平均冒充稳健。

### 失败 / 边界例（最少四类叙事槽）

| 类型 | 看什么 | 讨论里能支撑的句 | 禁止升级成 |
|---|---|---|---|
| 小目标漏检 | 原图面积<1024 的 GT 未匹配 | 低分辨整图易丢小目标 | 「某方法无价值」 |
| 误检抬升 | FP 集中在背景纹理/重叠切片 | 切片抬召回常付精度 | 「切片一定更差」 |
| 接缝 / 重复框 | 块边界物体 | 融合/NMS 超参敏感 | 未披露超参却指责方法 |
| 映射后空洞 | UAVDT 类无法对齐 | 外推评价上界受映射约束 | 回改映射刷分 |

每例固定四要素：**协议、图 ID 或序列、现象、不推广的边界句**。

### 主张允许 / 禁止（成稿前默写）

**允许：**

- 在冻结检测器上，推理协议系统性改变航拍小目标的召回–精度–代价权衡。  
- 双集上可复现「抬有效分辨率或切片覆盖 → 召回倾向上升并常伴代价」的粗趋势。  
- 图级配对下，某主比较对的 Δ 与 CI（仅限已冻结对）。

**禁止：**

- 宣布新检测器 / 新模块 / 新损失。  
- 「五方法跨数据集通论排序」。  
- 用 1660 开发时序冒充机载实时或 4090 正式时序。  
- 看 E 分后改映射或改 conf 再报终表。

### 练习

1. 画出你稿中的「近邻协议表」空表（含列名），并标明哪一对服务 C1、哪一对服务预算讨论。  
2. 从 Stage D 或 E 各指定一类失败例槽位，写四要素草稿（无图也可先写检索条件）。  
3. 用附录清单做一次自检：当前仓库缺哪 2 项？哪 2 项已具备？
