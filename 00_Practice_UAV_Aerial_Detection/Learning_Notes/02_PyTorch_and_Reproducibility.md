# 第一部分：必须掌握（知识链教材）

## 1. 学习目标

学完本块，你应能：

1. 闭卷沿知识链讲清一次检测／分类训练与验证的数据与计算路径；
2. 对最小训练循环逐行说明：张量大致形状、何处求梯度、train 与 eval 差在哪；
3. 写出一份最小复现清单，并说明 checkpoint 应恢复哪些状态；
4. 识别至少一种数据泄漏，并给出不泄漏的划分规则；
5. 用自己的话说明：这些能力如何支撑练手文的公平对照与 EI 协议主张（不编造未跑结果）。

## 2. 知识链（总览）

一条链，必须能顺讲，不能只背词：

```text
数据与标签
  → Dataset / DataLoader（batch、shuffle、collate）
  → forward（预测）
  → loss（与标签对齐）
  → backward / optimizer（更新）
  → validation（无反向、用于选模型）
  → checkpoint 与日志 / seed（可恢复、可复查）
```

旁路约束（挂在链上，不是另起炉灶）：

- **泄漏**：错误划分会让链上「validation」失去意义；
- **公平性**：只给新方法调参、基线默认，会污染后续实验卡（见笔记 03）。

## 3. 链上各节点（核心内容）

### N1 数据与标签

- 图像张量常见布局 `B×C×H×W`；dtype、device、归一化范围要一致。
- 检测标签是变长框＋类别，**不能**想当然堆成与分类相同的固定二维阵。
- shape 偶尔「能跑」仍可能语义错（静默错比报错更危险）。

### N2 Dataset / DataLoader

- `__len__` / `__getitem__`；transform 是否只用于 train。
- `shuffle`、`batch`、`num_workers`、`collate_fn` 各管什么。
- 同源：同视频邻帧、原图与增强副本，为何不能随机拆进 train/val/test。

### N3 forward

- `prediction = model(x)`：训练态与推理态输出形式可能不同（检测头）。
- 先保证张量路径对，再谈精度数字。

### N4 loss

- loss 比较「预测 vs 标签」；检测里常含分类＋框回归（＋分布）等项。
- 标签与预测必须在同一匹配规则下对齐（本块只要求概念，不要求手推 YOLO 全充分配）。

### N5 backward / optimizer

```text
model.train()
for batch:
    optimizer.zero_grad()
    pred = model(image)
    loss = criterion(pred, target)
    loss.backward()
    optimizer.step()
```

- 每一行的作用；验证阶段为何通常 **不** `backward`。
- SGD / AdamW、学习率、weight decay、warmup 的角色（不要求大规模搜参）。

### N6 validation

- `model.eval()` + `torch.no_grad()`：Dropout／BN 行为、不产生训练图。
- val 用于选模型与阈值；**test 只做最终评价**，不能来回调参。

### N7 checkpoint 与日志／seed

- checkpoint 至少：模型、优化器、epoch、配置；分清 resume 训练 vs 只加载推理权重。
- 正式 Run 最少记录：Run ID、代码版本、数据版本与 split、配置、seed、环境／硬件、指标与权重路径、是否异常。
- seed 固定≠全平台绝对确定性；关键结论需要多种子或明确限制。

## 5. 必答问题

1. 训练集、验证集、测试集各自允许做什么？不允许做什么？  
2. `train()`、`eval()`、`no_grad()` 区别是什么？验证时为何通常不 backward？  
3. 为什么视频邻帧随机划分可能虚高？给出一条不泄漏规则。  
4. 若方法 A 调了 20 组超参、基线只用默认，比较是否公平？为什么？  
5. 哪些信息缺失会使一次实验无法复现？（列至少 5 项）
