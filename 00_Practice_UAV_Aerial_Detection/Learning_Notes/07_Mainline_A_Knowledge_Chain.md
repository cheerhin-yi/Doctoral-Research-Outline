### 知识链

```text
冻结权重 last.pt（SHA 固定）
→ 方法协议（F640 / F1280 / DensK1 / UnifAll / SAHI640）
→ （可选）切片与坐标映射
→ 推理与 NMS / 融合
→ 原图空间评价（小目标）
→ 整帧耗时与超时
→ 图级配对统计（Stage F）
→ 跨集外推（Stage E，映射预冻结）
→ 主张措辞（C1/C2）与 EI 包装（→ 笔记 11）
```

### 五方法（只改协议，不改网络）

| 方法 | 核心操作 | 主要换取 | 主要代价 |
|---|---|---|---|
| F640 | 整图 imgsz=640 | 快 | 小目标易丢 |
| F1280 | 整图 imgsz=1280 | 更高有效分辨率 | 算力升 |
| DensK1 | 密度引导单片+底图 | 局部加精 | 选区失误→漏检 |
| UnifAll | 均匀全覆盖切片 | 覆盖全 | 延迟高 |
| SAHI640 | SAHI 切片协议 | 工程化切片 | 延迟很高 |

命名以 Tracker / `summary.json` 为准；磁盘文件夹名可能略异。DensK1 定义以已冻结 Run 为准；**未经授权不得改网络或重训**。

1. **Oracle 禁令：** 用 GT 引导选区得到的召回，不得写成可部署方法精度（C2）。

   当前科研下一门禁在 **EI 包装**（笔记 `11`），不是再开训练。
3. **主比较与包装：** 配对主叙事仍可突出关键近邻对（如 F1280 vs DensK1）；成稿时用 **近邻协议表** 展开多轴，避免只写总排名。UnifAll/SAHI 作预算边界对照。
4. **跨集纪律：** E 上名次与 D 不完全一致是预期现象；主张写「协议改变权衡」，不写「通论五方法排序」。细节见笔记 `09`。
