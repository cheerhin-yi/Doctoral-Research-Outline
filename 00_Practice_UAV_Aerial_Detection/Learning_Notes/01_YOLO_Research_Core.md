# 第一部分：必须掌握（知识链教材）

## 1. 学习目标

1. 闭卷沿知识链讲清 YOLO 式检测器从输入到评价的路径；
2. 自绘结构图：每节点标注输入／处理／输出；
3. 独立完成 IoU、Precision／Recall、简化 NMS 手算；
4. 把漏检／误检／定位偏／重复框映射回链上具体环节；
5. 说明「能跑 predict」≠ 理解检测链（对应练手文读表、写 EI 对照）。

## 2. 知识链（总览）

```text
输入图像（及预处理）
  → Backbone（表征）
  → Neck（多尺度融合，如 FPN/PAN 一类）
  → Head（分类＋框回归等）
  → 训练分支（匹配／损失） 与 推理分支（解码／阈值／NMS）
  → 评价（IoU 匹配 → TP/FP/FN → P/R/AP）
  → 误差诊断回流到结构或数据环节
```

## 3. 链上各节点

### N1 输入与预处理

- 分辨率、letterbox／缩放、归一化；尺度变化如何影响小目标像素面积。

### N2 Backbone

- 分层下采样与通道；深层语义 vs 浅层细节（ResNet 残差直觉可挂这里，细节见 `10_ResNet_Core`）。

### N3 Neck

- 为何需要多尺度特征；P3／P4／P5（或 P2）大致职责：小／中／大目标倾向。

### N4 Head

- 每层输出什么（类别、框、可能的分布／目标性）；共享头 vs 分头仅作概念（实现候选见 05，历史）。

### N5 训练分支 vs 推理分支

- 训练：标签匹配与损失（概念层）；通常**不**在训练步内做 NMS。
- 推理：解码 → 置信度阈值 → NMS → 最终框。

### N6 评价与手算

- IoU 定义；TP／FP／FN；Precision／Recall；AP 的直观含义（本块不要求手推全套 COCO 代码）。
- 简化 NMS：按分排序、压抑制 IoU 高的重复框。

### N7 误差映射

| 现象 | 可能落在链上何处（例） |
|---|---|
| 漏检 | 分辨率／浅层特征／阈值过高／匹配 |
| 误检 | 分类／背景抑制／阈值过低 |
| 定位偏 | 回归头／步长／小框量化 |
| 重复框 | NMS 阈值／多尺度重复预测 |
