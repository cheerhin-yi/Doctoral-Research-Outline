## 第一部分：必须掌握

### 学习目标

1. 能用**原图像素面积**定义小目标，并说明为何评价必须回到原图坐标。
2. 能解释 stride / 特征层与小目标覆盖的关系；区分「提高输入分辨率」与「切片再检测」。
3. 能把 P0 五方法放到「尺度处理手段」轴上，而不是当成五个新网络。

### 知识链

```text
原图目标面积
→ 小目标阈值（本项目：0 < w·h < 1024）
→ 缩放/切片如何改变特征覆盖
→ 检测与坐标还原
→ 原图空间匹配（IoU）
→ recall_small / precision（图级可配对）
```

### 链上要点

1. **本项目小目标：** 在**原图**上 `0 < w×h < 1024`。切片内变大不等于标签定义改变；匹配与召回统计仍回原图。
2. **F640 vs F1280：** 同一冻结权重下改变推理分辨率，是「尺度轴」对照，不是新模型。
3. **DensK1 / UnifAll / SAHI640：** 用局部高分辨率换整帧覆盖与时间；必须同时报超时/耗时，否则只剩乐观召回。
4. **忽略区与无效类：** VisDrone 的 ignore / others 不得当正样本；删标签 ≠ 像素级忽略监督（见 07 练习）。
5. **禁止归因错误：** 不得把 F1280 的增益说成「骨干更强」——骨干未改。

### 练习

1. 手算：原图框 `(x,y,w,h)=(100,200,20,15)`，面积是否算小目标？若整图缩放到 640（原图 1920 宽），该框面积约变成多少？评价时应用哪套坐标？
2. 用一句话区分：提高 `imgsz`、密度切片、均匀切片、SAHI。
3. 列出至少两个「看起来 AP 升了但不能支持 C1」的污染来源（例：改 conf、改 NMS、用 val 调参后报 test-dev）。

### 必答题

1. 为什么 small 定义必须锚定原图而不是切片图？
2. F1280 相对 F640 的 recall_small 上升，最多能支持什么主张？不能支持什么？
3. 若某图 `small_gt=0`，该图的 `recall_small` 在配对检验里应如何处理？
