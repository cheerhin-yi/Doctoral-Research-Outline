# Learning_Notes（练手文）

按研究路线分块学习。每篇主题笔记采用两部分：

1. **第一部分：必须掌握** — 学习目标、一条知识链、链上说明、练习、必答  
2. **第二部分：我的记录** — 按同一条链填写理解／证据／必答；过关只查这里  

| 文件 | 用途 |
|---|---|
| [`../Learning_Check_Baseline.md`](../Learning_Check_Baseline.md) | 助手维护的检查基准（过关依据） |
| [`../Completion_Metrics.md`](../Completion_Metrics.md) | 关卡总门 L0–L4 |
| `00_Unified_Core_Knowledge_Map.md` | 全局知识地图（导航） |
| `01`–`07`、`10_ResNet_Core.md` | 主题笔记 |
| `Learning_Record_Template.md` | 可选当日备忘；**过关以各笔记第二部分为准** |

## 顺序

1. 读 [`../Learning_Check_Baseline.md`](../Learning_Check_Baseline.md)  
2. 从 `01_YOLO_Research_Core.md` 起：读第一部分 → 填第二部分 → 交助手检查
