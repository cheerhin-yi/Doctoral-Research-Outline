# Learning_Notes（练手文）

按研究路线拆块学习。每一块一个主题笔记；**先知识链、后记录**。

| 文件 | 用途 |
|---|---|
| [`NOTE_FORMAT.md`](NOTE_FORMAT.md) | 笔记格式（两部分） |
| [`../Learning_Check_Baseline.md`](../Learning_Check_Baseline.md) | **助手维护的检查基准**；过关依据 |
| [`../Completion_Metrics.md`](../Completion_Metrics.md) | 关卡总门 L0–L4 |
| `00_Unified_Core_Knowledge_Map.md` | 全局知识地图（导航，单独不过关） |
| `01`–`07` | 各块主题笔记 |
| `Learning_Record_Template.md` | 可选：当日备忘；**过关证据以各笔记第二部分为准** |

## 推荐顺序

1. 读 `NOTE_FORMAT.md` + `../Learning_Check_Baseline.md`
2. 打开 `00_Overview/Current_Stage.md` 确认学习不与未授权实验冲突
3. 从 **`01_YOLO_Research_Core.md`** 起：读第一部分 → 填第二部分 → 交助手按基准检查
4. `PASSED` 后再进入下一块（见基准中的顺序表）
