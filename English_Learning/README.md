# 项目英语学习支持线

本目录服务于当前博士研究项目的英语能力建设，不属于七篇论文中的新研究方向，也不改变[当前科研阶段](../00_Overview/Current_Stage.md)的唯一任务。

## 🎯 当前基础与目标

- 当前基础：工作三年后重新系统学习，四级约350–400分。
- 近期目标：尽快读懂目标检测相关论文的摘要和当前需要的章节。
- 12周目标：能够先不依赖整句翻译或AI代写，独立起草英文论文主要段落。
- 24周目标：保持科研英语能力，并为学校下一次可报名的四级考试做好准备。
- 时间上限：每天30分钟，每周6天；周日休息或补漏。

英语能力可以并行训练，但英语材料必须跟随科研阶段。当前只学习YOLO完整检测链英语，不借英语学习提前精读LUD-YOLO、BPD-YOLO、EUAVDet或启动Paper 1及Paper 2–7内容。

## 📁 文件职责

- [领域英语课程](Domain_English_Lessons.md)：由AI按当前科研阶段提供术语、固定搭配、句型、例句、练习和答案。
- [学习进度记录](Progress_Log.md)：由用户保存闭卷测试、本人造句、短文初稿、修改稿、四级分项结果和薄弱点。

同一内容只保留一处。课程内容写在领域英语课程中，个人作答和进度只写在进度记录中，不再建立每日打卡文件或自行维护另一份大词表。

## ⏱️ 每天30分钟

普通学习日：

1. 8分钟：按第1、3、7、14和30天的间隔复习旧词组。
2. 10分钟：学习5个新术语或固定搭配。
3. 8分钟：完成阅读、听力、翻译或造句中的一项。
4. 4分钟：闭卷写出一个句子，或记录一个仍会犯的错误。

测试日不增加新词，用30分钟完成闭卷测试和短段落。当前第一模块含30项，因此安排6次学习和1次测试，共7个学习日；不为追赶日历压缩测试或延长每日时间。

## 📅 24周路线

### 第1–4周：结构和流程

学习YOLO检测链、评价指标以及描述输入、处理、输出的句型；同时补主动/被动语态、一般现在时和句子主干。

### 第5–8周：比较和因果

科研阶段允许后，学习PyTorch、实验设计、小目标与多尺度相关表达，以及比较、原因、结果、让步和条件句。

### 第9–12周：实验与论文起草

学习Method、Experiments和有限结论的写法。先保存本人初稿，再接受修改意见并由本人重写；没有运行证据的位置只保留占位符，不编造数字。

### 第13–20周：四级主攻

每周4次四级任务、2次科研英语维持。连续两次低于60%正确率的分项，下周增加一次该分项训练，但不增加每日总时长。

### 第21–24周：考试冲刺

完成限时分项训练。考前安排两次按当次官方时长进行的完整模拟，作为日常30分钟之外仅有的长时例外；内部目标是连续两次估分约450分。

如果学校下一次可报名考试早于第24周，考前4周切换到冲刺安排，考试后再继续未完成内容。

## 🧭 领域模块顺序

1. YOLO检测链、训练与推理：当前开放。
2. IoU、Precision、Recall、AP、mAP与错误分析：完成当前模块后开放。
3. PyTorch训练、验证与可复现性：等待科研阶段允许。
4. 公平对照、数据泄漏与不确定性：等待科研阶段允许。
5. 小目标、多尺度特征与P2–P5：等待科研阶段允许。
6. 轻量共享检测头：等待科研阶段允许。
7. 参数量、GFLOPs、显存、延迟与FPS：等待科研阶段允许。
8. 文献摘要、Method与Experiments阅读：等待文献阶段允许。
9. Introduction与Related Work写作：等待写作材料具备。
10. Method、Experiments、Results与Discussion写作：等待实验结果冻结。

后续模块只在前一模块通过且科研阶段允许后生成，不提前填充。

## 🤝 学习分工

AI负责：

- 从当前允许的材料中筛选高频、有用的领域表达；
- 提供中文解释、音标、搭配、例句、句型、练习和答案；
- 批改用户造句与段落，指出具体错误；
- 把遇到的新词分为“必须会用”“只需认识”或“当前忽略”；
- 根据周测试结果调整下一批内容。

用户负责：

- 按安排学习，不另找大词表；
- 先闭卷作答，再查看参考答案；
- 保存修改前的本人初稿；
- 根据反馈亲自重写，而不是直接用AI文本替换；
- 把遇到但不理解的词句记录下来，交由AI筛选。
