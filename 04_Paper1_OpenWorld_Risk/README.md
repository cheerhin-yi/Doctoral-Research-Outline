# Paper 1：无人机铁路开放环境风险感知

暂定题目：**Evaluating Track-Relative Spatial Representations for Risk Perception in UAV Railway Inspection**。

当前目标是在本轮16个弹性研究周内形成可复现的空间表示稳定性比较和完整初稿。研究周不绑定固定日历日期。主线是检验UAV高度、分辨率和轻度视角变化下，局部轨道宽度归一化侵界量是否优于原始像素及已有铁路空间表示。未知高风险识别与风险校准是条件扩展，不再作为默认核心创新。

**贡献边界**：轨道中心线/边界、标准轨距换算、距离风险分级、铁路开放集检测和风险校准均已有近邻工作；本项目不得宣称首次提出这些组成。参见`../01_Literature/Paper1_Novelty_Audit_2026-08-27.md`。
