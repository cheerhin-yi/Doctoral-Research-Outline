# Paper 5：多模态铁路风险理解

## 核心科学问题

视觉缺失或退化时，如何利用RF/ISAC或其他模态继续可靠理解风险？

## 候选创新

- Modality Reliability Modeling（待文献与实验核验）
- Missing/Degraded Modality Robustness（待文献与实验核验）
- Multimodal Calibrated Risk（待文献与实验核验）

## 输入

视觉风险语义、替代模态观测及各模态质量/可靠性。

## 输出

融合风险、模态可靠性、缺失处理和校准不确定性。
