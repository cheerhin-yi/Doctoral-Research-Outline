# 练手论文学习笔记使用说明

本目录独立保存练手论文需要的共同基础和专项知识，不依赖Paper 1中的笔记文件。开放世界与铁路风险不属于本论文范围，仍只保留在Paper 1。

| 顺序 | 笔记 | 必须留下的输出 |
|---:|---|---|
| 1 | [YOLO研究核心](01_YOLO_Research_Core.md) | 完整检测链、指标手算、公开航拍错误分类 |
| 2 | [PyTorch与可复现性](02_PyTorch_and_Reproducibility.md) | 训练流程、运行记录、数据泄漏检查 |
| 3 | [实验设计与不确定性](03_Experiment_Design_and_Uncertainty.md) | 公平对照、失败判据、统计与校准边界 |
| 4 | [小目标与多尺度检测](04_Small_Object_and_Multiscale.md) | 三种检测尺度结构图、stride计算、尺度选择说明 |
| 5 | [轻量共享检测头](05_Lightweight_Shared_Head.md) | 参数量手算、LSM-Head草图、实现检查表 |
| 6 | [速度评价与简单部署](06_Efficiency_and_Deployment.md) | 计时协议、指标对照、可选导出流程 |

每次学习直接填写对应文件：记录日期和资料，用自己的话回答问题，并至少留下一个可检查证据。不要另建零散学习任务清单。
