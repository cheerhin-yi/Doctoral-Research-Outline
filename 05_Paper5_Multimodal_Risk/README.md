# Paper 5：多模态铁路风险理解

**状态**：PAUSED；没有同步第二模态数据前不启动。

## 要回答的问题

雾、夜间、遮挡或视角退化导致视觉不可靠时，能否利用RF、ISAC或其他传感器继续形成可信风险判断？

## 预期输入与输出

- 输入：Paper 1视觉风险/未知性/不确定性，第二模态观测及模态质量；
- 输出：融合风险、模态可靠性、缺失模态处理和校准结果。

## 启动后需要学习

1. 多模态表征与早期/中期/后期融合；
2. 时间和空间同步；
3. 模态质量与可靠性建模；
4. 缺失、退化和冲突模态处理；
5. 多模态校准与公平消融。

## Paper 1怎样帮助

Paper 1提供视觉单模态强基线、风险定义和不确定性指标。Paper 5必须证明第二模态在视觉退化条件下产生真实增量，而不是只因参数更多。

## 启动门槛

- Paper 1视觉风险与可靠性基线稳定；
- 第二模态与视觉数据同步、合规且具有足够样本；
- 单模态强基线和缺失模态评价协议已定义；
- 完成多模态铁路风险最近工作审计。

## 已归档候选文献

[视觉退化稳健性候选原文](Literature/01_Adverse_Condition_Robustness/)讨论图像恢复与检测级联稳定性，可作为未来雾、低照等条件下的视觉单模态基线；它不是多模态融合证据。Paper 5仍为 `PAUSED`。
