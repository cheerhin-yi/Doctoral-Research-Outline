# N08 科研实验与评价

**状态**：ACTIVE / MUST  
**当前职责**：把前置论文A/B变成紧凑、无泄漏、可审稿的证据链。

## 1. 主张驱动规则

- A最多两个主要主张；
- 每个实验必须改变审稿人对某条主张或反解释的判断；
- 最多三类强基线；
- 最多五个核心证据块；
- MUST与NICE分开，NICE不得延迟投稿。

## 2. 数据规则

- 按完整`scene_id`划分训练、校准和测试；
- 同一布置、相邻帧、重复航线和增强衍生样本不得跨集合；
- 测试集不参与方法、变量、阈值和停止规则选择；
- 数据版本、来源、许可、字段和缺失值可追踪。

## 3. 当前五个证据块

1. E0：数据、指标和小样本校准Sanity；
2. E1：未校准及三类强校准基线；
3. E2：条件校准总体与最差视角结果；
4. E3：固定危险Recall、变量消融和观测有效性；
5. E4：场景聚类置信区间、失败分析和必要复现。

## 4. 每个实验必须登记

`Claim, Hypothesis, Variable, Control, Baseline, Dataset/Split, Metric, Success Criterion, Failure Interpretation, Figure/Table Target, Run ID`

## 5. 统计与复现

- 随机性影响核心结论时对保留配置运行3个种子；
- 置信区间按物理场景聚类Bootstrap；
- 同时报告效应方向、大小、区间和失败条件；
- 不只汇报最好结果；负结果必须形成KEEP/CUT/REVISE决定。

## 6. 最小练习

为A-E01至A-E06逐项写出主张、强基线、成功标准、失败解释和目标图表，并用一个小样本运行检查指标代码。

## 7. 完成门

- scene级划分和哈希审计通过；
- 主张—实验—图表可双向追踪；
- 没有不服务A1/A2的实验；
- 结论不超过数据和统计证据。
