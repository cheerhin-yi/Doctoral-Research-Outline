# 学习框架导航：前置论文A当前激活，按门槛串行学习

## 1. 使用原则

N01–N16共同服务两篇前置论文、两个桥接模块和七篇主论文，但不同时学习。当前唯一活动任务是**前置论文A：飞行条件感知风险校准**；Paper 1原学习线已经暂停。学习进度以[重启学习计划](../00_Project/Restarted_Learning_Plan_2026-08-28.md)和[20周执行清单](../00_Project/PrePaper_20_Week_Execution_Backlog.md)为准。

执行规则：

1. 当前研究周指定哪些笔记和章节，就只更新这些内容。
2. 一篇笔记不要求一次填满14章；先完成当前任务所需章节、复述和最小实验。
3. N05、N09–N16当前不作为学习欠账，不安排阅读、编码或实验。
4. 后续论文启动前先更新最近工作、科学问题和数据条件，再决定是否沿用现有笔记结构。
5. 仅因“以后可能用到”而阅读或实现，不计入前置论文A进度。
6. 当前只保留两个主要学习主张：条件校准改善最差视角可靠性；校准风险改善固定危险召回率下的误报。不能支撑这两个主张的内容延后。

## 5. 每次学习前的范围检查

- [ ] 这次学习是否由前置论文A当前周的MUST/SHOULD任务触发？
- [ ] 能否指出它服务A的哪条主张；若不能，是否已经到达后续模块启动门槛？
- [ ] 本次结束时是否会留下复述、公式检查、代码/练习或实验证据？
- [ ] 如果只是未来可能有用，是否应记录到开放问题后立即停止？
- [ ] 是否避免同时启动多个学习模块和多个论文实验？

当前范围检查不通过时，停止学习并把问题记入开放问题清单，不把它变成新的课程或实验线。
