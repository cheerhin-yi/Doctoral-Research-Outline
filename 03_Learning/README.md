# 学习框架导航：按论文启动，不按编号一次学完

## 1. 使用原则

N01–N16共同服务七篇论文，但不同时学习。当前只启动Paper 1所需模块；后续模块保留为研究接口，只有对应论文达到启动条件后才进入学习、复习和实验。

执行规则：

1. 当前研究周指定哪些笔记，就只更新哪些笔记。
2. 一篇笔记不要求一次填满14章；先完成当前任务所需章节、复述和最小实验。
3. N09–N16当前不作为学习欠账，不安排每日或每周打卡。
4. 后续论文启动前先更新最近工作、科学问题和数据条件，再决定是否沿用现有笔记结构。
5. 仅因“以后可能用到”而阅读或实现，不计入当前Paper 1进度。

## 5. 每次学习前的范围检查

- [ ] 这次学习是否由当前研究周的MUST/SHOULD任务触发？
- [ ] 能否指出它服务Paper 1的哪个RQ，或后续论文的哪个已启动问题？
- [ ] 本次结束时是否会留下复述、公式检查、代码/练习或实验证据？
- [ ] 如果只是未来可能有用，是否应记录到开放问题后立即停止？
- [ ] 是否避免同时启动多个学习模块和多个论文实验？
