核心创新是**残差块（Residual Block）** 和**跳跃连接（Skip Connection）**，专门用于解决深度神经网络在训练过程中出现的 “性能退化问题”（即当网络深度增加到一定程度后，模型的训练误差和测试误差反而会上升）。

用我自己的话理解有以下几个特点：

1. 残差块需要**1×1 → 3×3 → 1×1** 结构，**先降维、再升维**，输出和输入的维度一样。维度的改变：通过改变卷**积核的个数**进行升降。

   - 降维的作用：可以过滤掉图像很多没用的信息，相当于把关键信息融合起来，同时降维制造了一个信息瓶颈，把最核心的语义组合放进64通道
   - 升维的作用：将降维后的关键且纯净的信息重新渲染成高级维度，信噪比远高于原来的256
   - **1×1** 主要提取通道特征，观察像素的属性，可以提取多种信息，保留精华，丢弃冗余的其他信息，升维时可以将低维属性投影成在高维空间的线性投影，可以得到**通道间的语义共现**：即一个通道代表一个信息，多个通道综合起来，再加上3×3的空间特征，就可以知道这个像素的语义
   - **3×3**主要提取空间特征，即长宽，主要提取图像的轮廓。浅层网络
   - 跟这样编排可以降低计算量

2. 跳跃连接就是每层网络输出修改为  $F(x) + x$，没有用残差网络的输出都是$F(x)$，代码输出如下。前者学到的是输入和输出之间的扰动，由于始终有输入参与，不会过拟合或收敛，后者会有各种问题，深层后无法有效收敛。

3. 学习的主要内容：什么也没有多学，还是那固定几层的神经网络参数，只是训练输出的结果变了，之前是下一层网络的参数，现在是和输入相同的规律。

4. 网络层最终学习到的内容**举例：假设某个残差块的最优目标是要把输入图像轻微锐化一点。**

   - 如果 `x` 已经比较锐利，网络就让 `F(x)` 的所有输出都趋向于 0。这时权重被训练得近乎为 0，输出几乎就是 `x` 本身（恒等映射）。
   - 如果 `x` 还不够锐利，`F(x)` 就会被训练成“一个能提取边缘并增强的信号”，加到 `x` 上，正好实现锐化。

   所以，**这些卷积层参数所定义的映射内容，就是“从输入 `x` 到所需修正量 `F(x)` 的变换规律”**。这种修正量可以是：

   - 增强边缘细节
   - 抑制噪声
   - 调整对比度
   - 变换特征响应强弱 等等，它是一个与 `x` 同维度的“调整量场”。

5. 网络整体在学：从修正量到最终答案。假设一个网络有多个残差块，每个残差块都学习到一个修正量，逐步的修正就可以让整个网络学习到最终的抽象特征。

```python
"""
文件名: 7.6 残差网络（ResNet）的残差块实现
作者: 墨尘
日期: 2025/7/14
项目名: dl_env
备注: 实现ResNet的基础组件——残差块（Residual Block），包含跳跃连接和残差学习逻辑
"""
import torch
from torch import nn
from torch.nn import functional as F
from d2l import torch as d2l  # 用于后续扩展（如训练流程）
 
 
class Residual(nn.Module):  #@save
    """
    残差块（Residual Block）：ResNet的核心组件，通过跳跃连接实现残差学习
    参数:
        input_channels: 输入特征图的通道数
        num_channels: 输出特征图的通道数
        use_1x1conv: 是否使用1x1卷积（用于输入输出通道数/尺寸不匹配时的维度调整）
        strides: 第一个卷积层的步长（用于控制特征图尺寸是否缩小）
    """
    def __init__(self, input_channels, num_channels,
                 use_1x1conv=False, strides=1):
        super().__init__()
        # 第一个卷积层：3x3卷积，步长由strides指定，padding=1保证卷积后尺寸不变（当strides=1时）
        self.conv1 = nn.Conv2d(
            input_channels, num_channels,
            kernel_size=3, padding=1, stride=strides
        )
        # 第二个卷积层：3x3卷积，步长固定为1（保持尺寸），padding=1
        self.conv2 = nn.Conv2d(
            num_channels, num_channels,
            kernel_size=3, padding=1
        )
        # 1x1卷积层（可选）：用于调整输入X的通道数和尺寸，使与输出Y维度匹配
        if use_1x1conv:
            self.conv3 = nn.Conv2d(
                input_channels, num_channels,
                kernel_size=1, stride=strides  # 步长与conv1一致，确保尺寸同步调整
            )
        else:
            self.conv3 = None  # 不使用时为None
 
        # 批量规范化层（BN层）：每个卷积层后都接BN层，稳定训练
        self.bn1 = nn.BatchNorm2d(num_channels)  # 对应conv1的输出
        self.bn2 = nn.BatchNorm2d(num_channels)  # 对应conv2的输出
 
    def forward(self, X):
        """
        残差块的前向传播：实现残差学习（Y = F(X) + X）
        参数:
            X: 输入特征图，形状为(批量大小, input_channels, 高, 宽)
        返回:
            残差块的输出特征图，形状为(批量大小, num_channels, 高', 宽')
        """
        # 第一步：conv1 + BN + ReLU（残差函数F(X)的第一部分）
        Y = F.relu(self.bn1(self.conv1(X)))  # Y形状：(批量大小, num_channels, 高1, 宽1)
 
        # 第二步：conv2 + BN（残差函数F(X)的第二部分，暂不激活）
        Y = self.bn2(self.conv2(Y))  # Y形状：(批量大小, num_channels, 高2, 宽2)
 
        # 若使用1x1卷积，调整输入X的维度（通道数和尺寸）以匹配Y
        if self.conv3:
            X = self.conv3(X)  # X形状变为：(批量大小, num_channels, 高2, 宽2)
 
        # 核心：残差连接（跳跃连接）——将输入X与残差函数F(X)相加
        Y += X  # 此时Y和X维度必须完全一致（通道数、高、宽均相同）
 
        # 最后通过ReLU激活函数输出
        return F.relu(Y)
 
 
if __name__ == '__main__':
    # 测试1：输入输出通道数相同（3→3），不使用1x1卷积，步长为1（尺寸不变）
    blk = Residual(input_channels=3, num_channels=3)  # 输入3通道，输出3通道
    X = torch.rand(4, 3, 6, 6)  # 随机输入：4个样本，3通道，6x6尺寸
    Y = blk(X)
    print("测试1输出形状：", Y.shape)  # 输出：(4, 3, 6, 6)（通道和尺寸均不变）
 
    # 测试2：输入输出通道数不同（3→6），使用1x1卷积调整维度，步长为2（尺寸减半）
    blk = Residual(input_channels=3, num_channels=6, use_1x1conv=True, strides=2)
    print("测试2输出形状：", blk(X).shape)  # 输出：(4, 6, 3, 3)（通道加倍，尺寸减半）
```

## 升降维原理
设输入特征图的尺寸为$H×W×Cin​$（高、宽、输入通道数）。
- **卷积核形状**：每个 1×1 卷积核的尺寸为 $1×1×Cin​$。
- **输出通道数**：由**卷积核的个数** $Cout​$决定。
输出的特征图尺寸变为 $H×W×Cout$。
- **当 $Cout<Cin$​**：通道数减少，即**降维**（压缩）。
- **当 $Cout>Cin$​**：通道数增加，即**升维**（扩展）。
### 1×1卷积作用
**1. 跨通道的信息整合（特征组合）重点**  
这是1x1卷积最本质的作用。它每个输出点都对应输入所有通道上同一个位置像素的**加权线性组合**。这相当于在通道维度上做了一次“全连接”，让网络能自主学习如何将不同通道的信息（如纹理通道、边缘通道）**按最优权重混合**，生成新的特征。
**2. 引入非线性（增加模型能力）**  
1x1卷积层后通常会紧跟一个激活函数（如SiLU或ReLU）。虽然卷积本身是线性变换，但“**Conv 1x1 + 激活函数**”的组合，为网络引入了额外的非线性。这增强了网络的表达能力，让它能拟合更复杂的数据分布。
**3. 控制参数量的“节流阀”（瓶颈设计）**  
在C2f等模块中，1x1卷积常被用来**先降维再升维**（形成窄瓶颈）。假设输入输出都是512通道，直接用3x3卷积参数量巨大。先用1x1降到128，再用3x3提取特征，最后用1x1升回512。虽然层数变多了，但**总参数量大幅减少**，这是现代轻量化网络的关键手段。
**4. 替代全连接层（空间保持）** 
在某些需要全局信息的场景（如SENet注意力机制中），有时会用到全连接层。但全连接层会破坏空间结构。此时可用1x1卷积作为轻量级替代，它既能实现通道间的信息交互，又能**完美保留特征图的空间尺寸（H, W）**。
## 全连接神经网络
值得强调的是，**全连接的输入只能是一维**，作为神经网络最后几层才接入，用来分类的。
另外很多网络使用1x1卷积替代全连接
怎么分类的？
- **数学本质**：$Y=W⋅X+b$。
- **维度设计（至关重要）**：
    - 输入维度：$Din=2048$（由上面的 GAP 决定）。
    - 输出维度：$Dout=K$（**K 等于你的分类任务类别数**，比如 ImageNet 的 1000，或者猫狗分类的 2）。
    - **权重矩阵 WW 的大小**：$2048×K$。
