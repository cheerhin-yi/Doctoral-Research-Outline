# 阅读笔记 - Glimmer Net - 2026-02-09

## 研究内容

**研究背景**：
1. 无人机应急响应的性能约束：因设备有限的内存、续航及计算复杂度，对模型轻量化和计算实时性的要求较高
2. 传统轻量级的网络模型感知存在缺陷：现有轻量级 CNN）多采用**单尺度感受野 + 深度堆叠**实现多尺度特征提取，存在参数和 FLOPs 冗余

**研究目的及方向**：
1. 无人机机载边缘端轻量级卷积神经网络架构设计
2. 无人机的应急场景图像分类与目标识别
3. 分组卷积的跨尺度特征轻量化融合

**研究方法**：
1. **分组空洞深度卷积块（GDBlocks）**：论文核心创新方法，将输入通道按固定分组数（m=4）划分，为每组分配差异化扩张率（d=[1,2,2,3]），组内采用深度卷积提取特征，通过扩张率替代核大小实现多尺度感知，可在单卷积块内完成特征提取，无额外参数和FLOPs 开销。
2. **高效特征聚合器（Aggregator）**：论文另一核心创新方法，解决分组卷积的组间信息无法融合的问题；先对 GDBlocks 输出特征图按通道索引重组，使新组包含所有扩张率的多尺度特征，再与 Stage 输入特征图混合拼接，最后采用分组点卷积实现跨尺度特征融合，替代传统全连接 1×1 卷积，降低参数开销。

**相关其他研究方法**：
1. **MixConv的分组深度卷积思想**：是 GDBlocks 最核心的借鉴方法，MixConv 通过分组深度卷积为不同组分配不同核大小实现多尺度感知，GlimmerNet 则将 “变核大小” 改进为 “变扩张率”，避免核大小增加带来的参数开销，实现**恒定成本的多尺度感知**。
2. **TakuNet的无人机应急监测轻量CNN设计**：为本文对比的baseline模型，GlimmerNet 借鉴了其 Stem、Refiner、分类 Head 的模块设计思路，同时改进了其特征提取（从单扩张率深度卷积堆叠改为 GDBlocks）和特征融合（从全连接卷积改为 Aggregator）。

**研究结论**：
1. **数据集性能**：在 AIDERv2（无人机应急场景专用数据集，含地震、洪水、火灾、正常场景，共 16723 张图像）上，GlimmerNet 以 31K 参数、22.26M FLOPs 实现 0.966 的 F1-score，超越所有对比模型（包括 DiRecNetV2 的 0.964、TakuNet 的 0.958）；
2. **泛化性验证**：在原始 AIDER 数据集上 F1-score 达 0.942（参数 29.5K），在 TinyImageNet（200 类通用图像分类）上以 0.24M 参数实现 47.08% 的准确率，证明其不仅适用于应急场景，还可作为通用轻量级骨干网络；
3. 消融实验验证
   - 用 GDBlocks 替代 TakuNet 的普通深度卷积，F1-score 从 0.928 提升至 0.933，可证明多尺度感知的有效性；
   - 叠加 Aggregator 后，F1-score 进一步提升至 0.936可证明跨尺度融合的有效性；

## 内容流程

**基本流程**：
```
输入图像 → Stem块（降采样）→ 4个Stage块（GDBlocks + Aggregator）→ Downsampler → Refiner → 分类Head
```

**重点内容**：
1. GDBlocks模块的对多特征提取的轻量化
2. Aggregator解决分组卷积的组间信息无法融合的问题

## 问题讨论

**文章优势**：
1. 由于GlimmerNet 轻量化程度高，可适配如无人机机载资源模型受限的边缘设备。
2. 关于自然灾害识别能力优异，可满足具备对应急响应的高识别需求
3. 泛化能力强，可应用于通用数据集

**存在问题和痛点**：
1. **仅支持 RGB 单模态输入，适配性受限**：模型目前仅能处理 RGB 图像，在夜间、烟雾、大雾等低能见度应急场景下，RGB 图像的视觉特征缺失，模型无法实现有效分类
2. **缺乏实际无人机平台的部署**：论文仅在 GPU（RTX3090）上完成实验，未在无人机专用的嵌入式平台开展测试，未验证模型在实际平台上的能耗、续航等关键指标。
3. **网络架构的扩展性有限**：模型当前为适配无人机轻量化需求做了针对性的的架构精简，若需进一步提升精度或对泛化性，会导致参数 / FLOPs 快速上升。

**总结借鉴**：
1. 论文对改进CNN极致轻量化框架的基本思想，即GDBlocks模块，是否对铁路轨道的障碍物识别有相同效果
2. Aggregator替换传统点卷积用以提取深度卷积的通道间特征，替换部分目标识别网络模型中是否具有相同效果
