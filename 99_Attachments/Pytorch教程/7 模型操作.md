# 模型保存
## 只保存模型的参数
推荐这种方法，运行比较快，保存的文件比较小
```
state_sict = net.state_dict()
torch.savev(state_sict, path)
```
下面是保存 LeNet 的例子。在网络初始化中，把权值都设置为 2020，然后保存模型。
``` python
net = LeNet2() 

# "训练" 
print("训练前: ", net.features[0].weight[0, ...]) 
net.initialize() 
print("训练后: ", net.features[0].weight[0, ...]) 

path_model = "./model.pkl" 
path_state_dict = "./model_state_dict.pkl"

# 保存整个模型 
torch.save(net, path_model) 

# 保存模型参数 
net_state_dict = net.state_dict() 
torch.save(net_state_dict, path_state_dict)
```

## 模型的断点续训练
在训练过程中，可能由于某种意外原因如断点等导致训练终止，这时需要重新开始训练。断点续练是在训练过程中每隔一定次数的 epoch 就保存**模型的参数和优化器的参数**，这样如果意外终止训练了，下次就可以重新加载最新的**模型参数和优化器的参数**，在这个基础上继续训练。教程的方式没说清楚，用到的时候再说。
# 模型迁移
 大概步骤如下，后续用到在记录。
1.   获取预训练模型的参数
2. 使用`load_state_dict()`把参数加载到模型中
3. 修改输出层
4. 固定 feature extractor 的参数。这部分通常有 2 种做法：
    1. 固定卷积层的预训练参数。可以设置`requires_grad=False`或者`lr=0`
    2. 可以通过`params_group`给 feature extractor 设置一个较小的学习率
# # 使用 GPU 训练模型
使用 GPU 训练模型可以显著加速深度学习的训练过程。PyTorch 提供了简单的方法将模型和数据迁移到 GPU 上。

首先，检查是否有可用的 GPU：

```python
import torch
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print(device)
```

然后将模型和数据移动到 GPU：

```python
model = LeNet2().to(device)
input_data = torch.randn(32, 1, 28, 28).to(device)
output = model(input_data)
```

如果有多张 GPU，可以使用 `torch.nn.DataParallel` 将模型包装起来，实现数据并行，自动将输入数据划分到多个 GPU 上计算：

```python
if torch.cuda.device_count() > 1:
    model = torch.nn.DataParallel(model)
model.to(device) 
```
`device` 要指定某个 GPU 为 主 GPU，否则会报错。
这样，模型的前向传播和反向传播就会自动利用多个 GPU。注意：使用 `DataParallel` 后，模型参数的保存和加载需要额外注意：模型实际被包装了一层，保存时最好获取原始的模型参数：`model.module.state_dict()`。
另外，还可以使用 `DistributedDataParallel` 实现更高效的分布式训练（通常用于多机多卡），但对于单机多卡，`DataParallel` 足以满足大多数需求。
记得在训练循环中，每次迭代都要将数据移动到正确的 device 上。
