## 6. 文献与状态词

| 代号 | 含义 |
|---|---|
| W-0001 … W-0014 | 全局 Work ID（文献注册表中的唯一工作编号） |
| PASS（审计） | 文献身份／证据审计通过，**不等于**你已精读 DONE |
| SCREENED | 已过初筛／审计用途明确，本人精读未完成 |
| HOLD | 暂停／未成立／暂不推进 |
| DISMISSED | 书面否决（投入前创新性不足等）；**不一定**等于已实测无效 |
| BLOCKED | 实验或任务因门禁未开而不可执行 |
| DONE | 该任务／运行已完成（仍须看上下文是否含学习验收） |

## 7. 方法与数据简称

| 词 | 含义 |
|---|---|
| LSM-Head | Lightweight Shared（轻量共享）检测头方案；历史候选 |
| VisDrone | VisDrone2019 等航拍检测基准数据 |
| UAV-RSOD | 铁路场景相关公开数据候选（历史路径，多处 HOLD） |
| SAHI／QueryDet／ESOD／MRU-YOLO 等 | 近邻方法名，见 Literature 矩阵 |
| GFLV2 | Generalized Focal Loss v2（分布质量估计近邻） |
| NMS | Non-Maximum Suppression 非极大值抑制 |
| mAP／AP50 | 检测平均精度类指标 |
| ignore | 评测中忽略区域；训练时删正标签≠正确 ignore 监督 |
