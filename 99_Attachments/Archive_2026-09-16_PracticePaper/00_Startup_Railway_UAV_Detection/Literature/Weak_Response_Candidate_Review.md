## 1. 这次究竟提出什么

研究问题仍是：在固定整帧时间预算内，怎样利用有限局部高分辨率计算减少无人机已知小目标漏检。具体切入点是**粗检测最终没有输出框，但检测头仍留有弱类别响应的区域**。这与图像中完全没有可用响应不同，也不意味着真实数据已证明存在足够数量的这类可恢复目标。

本批唯一机制假设：同一次普通YOLO前向中，一个位置在P3与P4对同一类别均有相对周围背景突出的响应，可能比绝对置信度／低阈值计数更能指示局部放大的恢复价值。将这一跨尺度对应关系用于区域排序；不增加检测头、注意力、损失、蒸馏、超分辨率、第二次全图探测或顺序反馈网络。

暂用描述性名称，不命名新YOLO架构。贡献如果能成立，应是**针对阈值下残余信号的选区判据及其有效条件**，不是“第一次使用弱信号”“第一次免训练裁剪”或“把预算换成毫秒”。

## 2. 为什么只是值得检验，而不是已有效

依据已有源码，普通YOLO分类分数在阈值／NMS前存在，P3/P4对应不同空间尺度；这是可读取的输入，不是需要GT才知道的位置。由此提出推测：部分真小目标绝对响应低，却可能在局部背景中突出，并有较粗层的同类支持。单看置信度可能选到绝对分数更高的背景；只看P3峰值也可能选到纹理。跨层空间与类别对应提供一个可检验的附加条件。

但是P3/P4共享网络，**不是独立传感器或独立概率证据**。极小目标可能已在P4消失；共同背景纹理也可能在两层一致；局部归一化可能放大噪声。这些都可能直接否决候选。现有模型权重尚未准入，未观察真实响应，不声称上述现象已在VisDrone被证实。

## 3. 可实施的单机制草案v0.1（未实现）

固定普通YOLO11n及同一组全图／局部权重。读取一次640输入全图前向的P3/P4类别logit，按真实特征尺寸和letterbox映射还原坐标；不将训练ignore标注、GT框或测试密度作为输入。精确导出接口仍须运行核验，已有静态源码不等于真实张量已验证。

以下数值只是预先写明的首个可证伪实例，不是最优值或性能承诺：

1. 对每个P3位置p取logit最高类别c，保留该类3×3邻域局部极大值；并列按行列索引。仅使用原图有效范围，剔除padding响应。
2. 对该类别分别在P3的9×9邻域与P4的5×5邻域计算中位数与MAD，邻域不含中心、边界用有效邻居。P3中心投影到最近P4格点q（距离并列按行列），要求q的最高类别也是c。两层按各自统计定义`z=clip((logit−median)/max(MAD,0.1),0,6)`；这是启发式局部对比，不是置信概率或统计显著性检验。
3. 位置得分为`u(p)=z3(p,c)×z4(q,c)`。若类别不一致则为0。全图同类、分数≥0.25的最终框已覆盖的位置作为已解释响应剔除；此规则必须在低阈值和单尺度对照中保持相同，不能把剔除本身冒充跨尺度贡献。
4. 使用既有固定640原图像素候选窗口、步长512和贴边规则；每个区域累加最高8个剩余正峰值。同分固定索引；不足8个用全部，无正峰则该区域分数0。默认不增加随机探索／额外回退机制。
5. 得到一次静态排序，沿共同的时间准入器选取容纳得下的窗口；零分窗口不选。不读取后续局部结果来重排。区域选择、响应读取／归一化、裁片、前向、回映和同一合并全部计时。预算不足只保留全图结果；没有成本上界时只报告实测超时比例，不能称硬实时保证。

只有第2–3步的跨尺度同类局部支持是本候选待证明的核心。裁片、预算准入、局部峰聚合、最终融合都是控制条件或实现选择。若中位数／MAD等操作使总成本不合算，不得从计时中去掉它们，也不通过增加第二模块挽救。

## 4. 与低阈值究竟有什么不同

数学上可以不同：设两个区域各有一个未被全图框解释的峰。A的原始类别分数0.08，局部标准化后P3/P4为4和3；B原始分数0.15，两层为1和0。候选得分A=12、B=0；绝对分数排序则B优先。这个**人工设定**仅说明候选不必是置信度单调变换，不是实验，不说明这种情况在真目标上更常见。

同时存在立即失败的反例：真目标P3明显、P4无同类支持，则乘积0；背景在两层均突出则高分误选。即便A被优先选择，优势也可能全部来自P3局部归一化，而非跨尺度。因此不能用这个算例或一个漂亮热图确认贡献。

## 6. 最小区分诊断：什么证据才值得继续

以下是执行准入后的诊断要求，本轮未运行。所有方法固定检测器、候选、融合、数据清单及输出阈值，先在相同片数K=2下比较，再计算同整帧时间预算的结果；两个问题分别报告。核心对照为：

| 对照 | 隔离的问题 |
|---|---|
| 既有预测密度Top-K；低阈值0.25/0.05/0.01/0.001的简单响应计数 | 是否只相当于降低阈值；所有预设阈值都报告，不在评价侧挑有利阈值 |
| 原始置信度Top-M响应，M与候选保留峰数匹配 | 是否仅因为使用更多弱响应；共同候选及聚合条件一致 |
| P3局部对比峰，关闭P4条件 | 是否仅为单尺度局部显著性，不需要跨层机制 |
| P3/P4原始分数乘积，关闭局部归一化 | 是否只是普通跨层分数合并 |
| 保持P4数值／类别分布但固定循环平移半幅，破坏空间对应 | 是否真的利用跨层位置对应，而非增加一个权重；边界与有效区规则必须一致 |
| 完整候选 | 其余条件均相同，已解释响应剔除作为共同控制条件 |

真实GT只用于诊断标签：在固定低阈值导出、匹配规则与候选池下，定义全图漏检但至少一个固定局部视图可检出的有效小GT。报告其总量、被所选区域实际检出的比例、整图整体AP／误检、各类结果与时间分布。区域“零粗框”按固定0.25阈值定义，不能事后改阈值美化盲区；无可恢复GT时分母N/A。裁片缓存可比较准确率，但不能把缓存读取算作实际运行速度。

**停止条件**：低阈值或P3-only已解释收益；打乱对应几乎不影响结果；P4条件主要删除可恢复真目标；收益依赖更多裁片／不同融合；响应操作开销抵消同预算收益；或可靠来源／最小统计规模无法支持结论。任何一项出现都保留失败，不自动叠加模块。正式独立泛化仍受来源组Unknown限制。
