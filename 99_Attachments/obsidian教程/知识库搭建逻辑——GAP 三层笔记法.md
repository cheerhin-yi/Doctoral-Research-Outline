GAP三层笔记法是用三个文件夹来管理所有笔记：采集（Grasp）、归类（Arrange）、表达（Present）。从文件夹的名字就可以看出，这三个文件夹分别代表了知识处理的三个阶段——收集、整理、产出。下面主要以论文方式为主。
# 采集
是收集知识的第一个阶段。可以使文章、摘录、网页剪藏等形式，也可以是碎片化的知识。需要注意的是：
- 不能过度收集，围绕输出采集
- 多记录自己的想法和经验
# 归类
也就是梳理。而且要**定期梳理**，不能让采集内容积累过多，梳理后采集内容可以另存起来或删掉。归类方法可以按照本身的**主题和领域**来组合分类。最好**每天采集**后内容后**当天晚上**都整理一遍。
# 表达
经过采集和整理的目录肯定和表达文件夹中的某些页面是高度关联的。在表达文件夹中，应该有一些我们提前建好的想要产出的内容。这时我们就可以把采集、归类这两个文件夹中的一些内容，直接关联到最后的表达笔记中。
# 论文案例
## **采集阶段**：随手收集素材，别管乱不乱。
泛读内容，写论文的话，暂时现总结这些：
1. 课堂PPT和讲义的总结笔记。
2. 读论文时随手记下的观点。
    - 可以记录论文中的不足
    - 综述中的展望和未来发展趋势等
    - 论文中提到的方法
3. 在图书馆翻书、拍下来的重要段落。
4. 和导师讨论后记下的灵感或问题。
5. 在散步时突然想到的研究角度（直接录音转文字）。
#### 采集工作流
> 明确想要解决的问题->阅读资料，记录下内容->快速整理收集
1. 明确的目标，一般分为三类。
	1. 要解决的问题
	2. 想表达的内容
	3. 需要完成的任务 
2. 看资源和写记录
3. 配置好工具和模板，在进行搜集，快速整理收集包含**三个关键要素**：
	1. 采集时间：自动记录采集的时间，方便未来回顾时判断信息的时效性。
	2. 是否已整理的标签（“刚开始”“进展中”“已完成”）
	3. 和其他笔记的链接位置
## **归类阶段**：定期整理，把素材变成可用板块。
归类文件夹中建了5个笔记，毕业论文分别是引言、文献综述、研究方法、研究结果、讨论，对应需要写的论文的五个主要部分。白天的采集笔记，晚上进行整理，整理的过程就是把素材关联到对应的归类笔记中。分别将采集的笔记、摘录、想法等关联到对应的笔记中，实现从碎片到板块的转化。
#### 整理工作流
主要完成两件事： 
- 处理未整理的采集笔记
- 梳理和优化归类笔记
	归类笔记中的内容足够丰富，还可以进一步新建表达笔记，为产出做好准备。需要准备两个模板，分别是归类笔记模板和表达笔记模板。加入必备的内容：相关笔记链接和笔记状态（“刚开始”“进展中”“已完成”）
##### 重点：笔记关联
1. 没有对应的归类笔记：需要新建一个归类笔记，把采集笔记内容放进去，要包括两个字段。一是“**链接**”，用来放置所有相关笔记；二是“**归类状态**”， 标注这个笔记是刚刚开始、正在收集中，还是已经成熟，便于日后回顾与管理。
2. 归类文件夹中，已经形成了对应的主题笔记：只需将新的采集笔记链接到已有的归类笔记中就行
3. 如果这条采集笔记与你正在撰写或计划撰写的某个表达笔记密切相关，那么可以跳过归类环节，直接将其关联到表达笔记
##### 整理方法
1. 归类笔记本来就是某个主题的汇总，如果内容太多且有几个子方向越来越清晰时，就应该果断地把它拆成多个更聚焦的小笔记。
2. 如果某个归类笔记下的内容已经足够成熟、结构也很清晰， 那么就可以用模板新建一个表达笔记，准备进入内容创作阶段。
3. 当你创建的归类笔记越来越多时，可以专门做一个“主题目录页面”，把所有的归类笔记以列表或分组的形式整理在一起，并附上每个主题的简单说明。
4. 收藏重要页面
### 表达阶段：动笔写作，直接从归类好的材料下手。
##### 表达产出的工作流
分为以下四个主要操作
1. 有表达欲望，创建表达笔记：不管是要解决的问题、想表达的观点， 还是必须完成的任务，只要你明确了这个目标，就可以新建一个表达笔记。
2. 完成表达笔记撰写：这里会用到左右分屏查找素材、AI 辅助写作等高效工具。
3. 整理表达笔记，汇入知识库：整理后的表达笔记要修改好状态、链接到相关归类笔记，并准备好以便日后循环利用。
4. 发表表达笔记（可选）：如果你希望让更多人看到自己的表达，可以选择合适的平台进行发布，比如公众号、博客或小红书。
##### 小技巧
1. 启动仪式在开始写作之前，给自己设定一个固定的“小仪式”，比如泡一杯咖啡、整理好桌面、戴上降噪耳机。这些动作能帮助大脑进入专注状态，形成心理暗示：我要进入工作时间了。
2. 数字戒断在产出期间，主动远离一切干扰源。可以把手机放在看不到的地方、关闭社交媒体的网页。这一步对保持深度专注非常关键。
3. 番茄时钟法这也是很经典的注意力集中法。用 25 分钟全力工作 + 5 分钟休息的循环节奏， 提高专注力的持续时间，还能避免长时间工作带来的疲劳感。
##### 管理
1. 最重要的就是把表达笔记和知识库中已有的归类笔记链接起来。表达笔记，应该可以和某个或某几个归类笔记建立链接。
2. 针对所有的表达笔记做一个目录页，做法和做归类笔记的目录类似。
3. 给所有笔记标记好状态
4. 采集笔记代码
	```dataview table WHERE contains(file.tags, “未整理”) ```
5. 提取未完成的归类笔记、表达笔记
	```dataview table WHERE contains(file.tags, “刚开始”) OR contains(file.tags, “进展中”) ```
6. 提取出来的笔记展示：将这些目录笔记整合到 Canvas（ 画板） 插件中，方便展示
