# 常用快捷键
Ctrl/Cmd+M：移动当前笔记到一个新的文件夹（默认快捷键）。
Ctrl/Cmd+O：搜索笔记（默认快捷键）。
Ctrl/Cmd+T：打开今天记的笔记。
Ctrl/Cmd+[：快速回到上一个笔记页面。
Ctrl/Cmd+]：快速去到下一个笔记页面。
Ctrl/Cmd+L：生成一条待办清单。

# 插件
Obsidian Web Clipper网页内容一键剪藏

常用AI插件：
**Copilot**：可以直接和单篇笔记对话，也可以利用整个仓库中的笔记来生成答案。
**Text Generator**：可以直接在笔记中进行续写，也可以很方便地调用存储的提示词。
**Smart Composer**：该插件不仅可以读取你的笔记，还能读取网址中的内容，写出来的内容可以直接应用在你的笔记中。

4. 信息整理：笔记整理的方法总结下来有三种：

	- 标签管理：避免（1）标签重复
