## Week 1 · 共同基础（YOLO / 指标 / 可复现）

### D01 · YOLO 检测链总览

- **学习目标**：闭卷沿链讲清完整检测流程及训练/推理分叉。  
- **核心内容**：RGB 输入与预处理；Backbone / Neck / Head 职责；训练分支（分配、loss）vs 推理分支（解码、NMS、评价）。  
- **练习/证据**：自绘箭头链（手绘或 Mermaid），每节点标注输入/处理/输出；对照旧笔记 `01_YOLO_Research_Core` 只补缺口。  
- **必答题**：  
  1. 训练时为何通常不做 NMS？推理时为何通常不算检测 loss？  
  2. Neck 与 Head 各向下一环节交付什么？  
  3. “能跑 `predict`”为何不等于理解检测链？  
- **验收**：闭卷口述完整链且无环节错位；结构图可被他人按节点复查。

### D02 · Backbone 与多尺度特征

- **学习目标**：说明 stride 如何改变分辨率/语义，以及小目标可能在何处丢失。  
- **核心内容**：典型 P2–P5 stride（4/8/16/32）；640 输入下特征图尺寸；加深/加宽为何未必救小目标。  
- **练习/证据**：给定 640×640，填写 P2–P5 特征图高宽；对 8×8 目标估算各层覆盖单元。  
- **必答题**：  
  1. P3 与 P5 各更适合什么尺度目标？为什么？  
  2. 只提高输入分辨率与增加 P2 有何不同？  
  3. 特征图上目标不足约 1 个单元时意味着什么？  
- **验收**：手算表正确（允许注明非整除以实网为准）；能解释“信息可能不可恢复”。

### D03 · Head、损失、解码与 NMS

- **学习目标**：讲清预测如何变成 loss 或最终框，以及 NMS 解决什么。  
- **核心内容**：分类/回归输出；标签分配直觉；框解码；IoU 阈值与 NMS 去重。  
- **练习/证据**：一组 IoU 手算 + 简化 NMS（给定分数与 IoU 矩阵，写出保留框顺序）。  
- **必答题**：  
  1. 高分类分但定位差，更可能出在哪类错误？  
  2. NMS 阈值过严/过松各会怎样伤害指标？  
  3. 重复框主要关联检测链哪一环节？  
- **验收**：手算步骤可复查；能区分漏检/误检/定位偏差/重复框。

### D04 · 检测指标手算

- **学习目标**：独立完成 IoU、Precision、Recall，并解释 AP/mAP 评价范围。  
- **核心内容**：TP/FP/FN；PR 曲线直觉；AP vs mAP；小目标分组指标为何可能与总体 mAP 方向不同。  
- **练习/证据**：构造小例子（若干预测与 GT）手算 P/R；写清 AP50 与 mAP50–95 各自回答什么。  
- **必答题**：  
  1. Recall 高、Precision 低通常意味着什么？  
  2. 为何不能只用总体 mAP 证明“小目标变好”？  
  3. 评价代码与训练标签语义不一致时会发生什么？  
- **验收**：手算与定义一致；错误类型能映射回结构环节（现象→证据→候选原因）。

### D05 · PyTorch 训练与验证链

- **学习目标**：沿数据→forward→loss→backward→optimizer→validation→checkpoint 复述。  
- **核心内容**：Tensor 形状 BCHW；Dataset/DataLoader；`train()`/`eval()`；`no_grad`；最小训练循环。  
- **练习/证据**：对最小循环逐行标注形状/梯度位置/训验差异（可读现有示例代码，**不启动正式训练**）。  
- **必答题**：  
  1. 验证时为何不 `backward`？  
  2. BatchNorm/Dropout 在 train 与 eval 下有何行为差？  
  3. 检测标签为何不能简单堆成固定二维数组？  
- **验收**：闭卷讲清循环；能指出至少一处若模式切错会出现的可观察现象。

### D06 · 可复现性与数据划分

- **学习目标**：列出最小复现清单，并能识别来源泄漏。  
- **核心内容**：seed、环境、配置、AMP、checkpoint、日志、Run ID；训/验/测职责；邻帧与增强副本泄漏。  
- **练习/证据**：写一份“别人能照做”的复现清单；给一个泄漏案例并写出不泄漏重划分规则。  
- **必答题**：  
  1. 哪些因素即使固定 seed 仍可能不完全确定？  
  2. 原图在训练、裁剪图在测试为何算泄漏？  
  3. 测试集调阈值破坏了什么？  
- **验收**：清单完整；泄漏路径与修正规则清楚。

### D07 · Week1 复习 / 补漏门

- **学习目标**：合上资料通过 Week1 综合检查；缺口记入 REPEAT 清单。  
- **核心内容**：D01–D06 压缩复述；错题重做；不新开大主题。  
- **练习/证据**：闭卷口述检测链；重做 1 组 IoU+P/R+NMS；复现清单抽查。  
- **必答题**（抽 3）：检测链分叉；P2–P5 尺寸；NMS 步骤；泄漏例子；train/eval 差异。  
- **验收（周门）**：检测链 + 指标手算 + 复现/泄漏三项均达协议阈值；未达标项标 `REPEAT`，不提前宣称 PASSED。

## Week 2 · 共享轻量（历史候选）+ 小目标 / 多尺度

> 线索 A 整周按**历史候选知识**学习，用于理解效率与结构权衡，**不**将其设为已定创新或固定未来方向。

### D08 · 小目标、stride 与覆盖

- **学习目标**：手算目标在各层覆盖，解释下采样导致的不可恢复风险。  
- **核心内容**：像素尺寸 vs 特征覆盖；AP_small / Recall_small；航拍小目标常见失效模式。  
- **练习/证据**：输入 640，目标 8×8 / 16×16 / 32×32，填 P2–P5 覆盖表。  
- **必答题**：  
  1. 小目标在深层“消失”是分辨率问题还是语义问题为主？  
  2. 为何 AP_small 与 mAP 可能反向？  
  3. 仅看可视化亮框为何不够？  
- **验收**：覆盖表正确；能连接到是否需要更高分辨率特征或局部高分辨率策略（为 Week3 铺垫）。

### D09 · 多尺度层职责与代价

- **学习目标**：说明各尺度层职责及加入高分辨率层的计算/访存代价。  
- **核心内容**：P2 收益与退化风险；提高输入分辨率 vs 加检测层；公平对照需固定什么。  
- **练习/证据**：写“若只改是否含 P2”的对照表（唯一变量、控制项、成功/失败解释）。  
- **必答题**：  
  1. 为何不能把“更大输入 + 新头 + 更多 epoch”的增益归因给单一模块？  
  2. 移除 P5 可能伤害什么？  
  3. 什么结果说明加 P2 不值得？  
- **验收**：对照设计无混杂；代价与精度主张分开陈述。

### D10 · 共享头 vs 独立头（历史候选）

- **学习目标**：讲清多尺度输入如何对齐通道、进入共享干路、再由尺度独立输出层预测。  
- **核心内容**：独立头参数重复来源；共享前提与仍需独立输出层的原因；**LSM-Head = 历史候选结构草图，非已验证 novelty**。  
- **练习/证据**：画基线独立头 vs 共享头对照图，标注张量形状与共享边界。  
- **必答题**：  
  1. 共享什么、不共享什么？  
  2. 跨尺度共享的前提是什么？  
  3. 为何参数变少仍可能不快？  
- **验收**：结构边界清楚；书面声明“候选/历史”，无“已证明创新”措辞。

### D11 · 深度可分离 / 分组卷积与参数手算

- **学习目标**：手算普通卷积 vs DW+PW 参数量，并讨论表达能力与部署。  
- **核心内容**：\(P_{conv}=K^2 C_{in}C_{out}\)；\(P_{ds}=K^2C_{in}+C_{in}C_{out}\)；分组卷积直觉；ONNX/设备算子差异。  
- **练习/证据**：选一组真实量级通道完成参数表；指出共享前后重复参数。  
- **必答题**：  
  1. 深度可分离节省的是参数还是一定节省延迟？  
  2. 访存瓶颈何时主导？  
  3. 若共享头失败，为何不默认叠注意力？  
- **验收**：手算正确；结论区分理论复杂度与实测速度。

### D12 · 效率指标与可复核测速

- **学习目标**：区分 Params、GFLOPs、显存、延迟、FPS；写出 batch=1 测速协议。  
- **核心内容**：纯推理 vs 端到端；预热、同步、重复、计时边界；mean / p95；与线索 B 时间预算的衔接。  
- **练习/证据**：写别人能照做的测速步骤；举“GFLOPs 更低但延迟更高”的合理解释。  
- **必答题**：  
  1. 为何不能用台式 GPU 速度宣称机载实时？  
  2. 漏计预处理/NMS 会如何扭曲加速比？  
  3. p95 相对均值多回答了什么？  
- **验收**：协议字段齐全；指标与主张匹配正确。

### D13 · 小目标失效分析

- **学习目标**：从错误证据回到结构/数据/评价环节，决定是否改结构。  
- **核心内容**：漏检/误检/定位/重复；密度、截断、忽略区；“改头 / 改数据 / 改协议”决策树。  
- **练习/证据**：至少两个错误案例写“现象→证据→候选原因→是否改结构”。  
- **必答题**：  
  1. 何种漏检更应怀疑分辨率不足？  
  2. 何种情况应先查标签与 ignore？  
  3. 负结果应删除主张、收缩主张还是换问题？  
- **验收**：判断链完整；不把未验证原因写成定论。

### D14 · Week2 复习 / 补漏门

- **学习目标**：通过线索 A + 小目标/多尺度综合门。  
- **核心内容**：覆盖手算、共享边界、参数手算、测速协议、失效案例复查。  
- **练习/证据**：闭卷讲清“历史候选 LSM-Head 学了什么、不能主张什么”；重做参数与覆盖各一题。  
- **必答题**（抽 3）：覆盖计算；共享边界；DW 参数；测速字段；失效归因。  
- **验收（周门）**：小目标/多尺度 + 共享轻量知识 + 效率协议达标；LSM-Head 定位正确（候选非定论）。

## Week 3 · 局部高分辨率 / 时间预算 + 文献 / 主张 / 实验综合

> 线索 B 为主；结合已归档负结果作**反例教材**，不重跑实验。

### D15 · 切片、重叠与坐标恢复

- **学习目标**：完成“原图→切片→局部框→全图框”的坐标链手算。  
- **核心内容**：切片原点、重叠、边界截断；左上角框 vs YOLO 归一化中心框；缩放与补边顺序。  
- **练习/证据**：沿用/改编 07 笔记坐标题：归一化、切片内坐标、放大后还原（保留本人演算纸）。  
- **必答题**：  
  1. 先偏移再缩放 vs 先缩放再偏移，错序会怎样？  
  2. 重叠区重复框如何产生？  
  3. 边界截断如何同时影响召回与定位？  
- **验收**：三步坐标题概念正确；算术笔误与概念错误可区分记录。

### D16 · 合并、NMS/融合与选区信号

- **学习目标**：区分合并策略，并严格分开 oracle 与可部署信号。  
- **核心内容**：全图 NMS / 分片融合；ROI/选区；**GT-oracle 选区不可证明部署效果**；未选区域仍可能有已知类目标。  
- **练习/证据**：用自然语言或草图说明“未选区域漏检”失败链；写清 oracle 结果允许与禁止的表述。  
- **必答题**：  
  1. 为何“按 GT 裁有目标区域”的高 Recall 不能直接当部署证明？  
  2. oracle 结果仍可用于什么（离线上界/诊断）？  
  3. 弱可部署信号与不可部署信号的界限？  
- **验收**：oracle 边界陈述正确；失败链完整。

### D17 · 时间预算约束全流水线

- **学习目标**：定义端到端计时链，并解释 mean / p95 / 超时率。  
- **核心内容**：计时起点→区域获取→裁剪/传输→检测→合并→结束；网络耗时 ≠ 整帧延迟；预算超时即失败模式。  
- **练习/证据**：列计时范围清单并标出易漏计环节；对假想数字解释为何只报均值不够。  
- **必答题**：  
  1. 参数量更低但整帧更慢是否可能？举例。  
  2. 超时率相对平均延迟多回答了什么？  
  3. 强 F1280 全图基线在时间预算叙事里扮演什么角色？  
- **验收**：清单覆盖端到端；统计量与主张匹配。

### D18 · 强基线、来源分组、忽略区与评价

- **学习目标**：说明公平强基线、泄漏防控与 ignore 语义。  
- **核心内容**：F1280 类强基线对照意义；原始来源→邻帧→增强副本→分组；删掉 ignore 标签 ≠ 训练时忽略该区域；有效真值与官方评价。  
- **练习/证据**：回答 07 笔记“忽略标签与训练监督”题；写一条来源泄漏例子与分组依据。  
- **必答题**：  
  1. “确定没有目标”与“不作为可靠正标签”区别？  
  2. Unknown 来源组应如何处理？  
  3. 开发集反复调参对测试主张有何风险？  
- **验收**：ignore 与泄漏概念正确；基线角色叙述不夸大旧实验结论。

### D19 · 文献阅读与 novelty 审计

- **学习目标**：用近邻比较写清“已有覆盖 / 候选差异 / 可证伪点”。  
- **核心内容**：摘要—方法—数据—对照—局限；冲突风险；书面否决 vs 实测失败。  
- **练习/证据**：选 1 篇已有审计或摘要，填迷你审计卡（问题、方法、差异、证据强度、对项目影响）。  
- **必答题**：  
  1. 何谓“无独立机制差异”？  
  2. 为何书面 DISMISS 不能写成“实验证明无效”？  
  3. 学习阶段 novelty 审计的产出应是什么（决策信息而非新训练）？  
- **验收**：审计卡无抄袭式摘抄；主张边界诚实。

### D20 · 实验设计综合（通向 3 个月阶段）

- **学习目标**：把一条候选主张写成可失败实验，但不执行训练。  
- **核心内容**：Claim→Hypothesis→唯一自变量→控制→强基线→划分→指标→成功门→失败解释；线索 A/B 各自可怎样被证伪。  
- **练习/证据**：写 1 份最小实验卡（线索 B 优先；线索 A 仅作可选对照说明）；列出 3 个月阶段需先冻结的协议问题清单。  
- **必答题**：  
  1. 本卡的唯一变量是什么？若混杂如何改？  
  2. 负结果时删除、收缩还是换问题？  
  3. LEARNING-CORE 结束后讨论 3 个月计划前，还缺哪些知识/协议门？  
- **验收**：实验卡可证伪；明确“尚未获准运行”。

### D21 · 三周终门 + 下一阶段讨论提纲

- **学习目标**：综合闭卷证明核心能力；整理 3 个月实验讨论议程（讨论≠开工）。  
- **核心内容**：Week1–3 抽检；知识地图自评；英语阶段耦合回顾；实验重设计议程草稿。  
- **练习/证据**：终门答卷（见评估协议）；`Learning_Record` 汇总；3 个月讨论提纲（问题、基线、预算、数据门、停止条件）。  
- **必答题**：  
  1. 两条创新线索当前各自的证据边界？  
  2. 为何归档负结果不能直接当下一方法的正论据？  
  3. 若终门部分 REPEAT，如何排补学而不偷偷开训？  
- **验收（三周门）**：共同基础 + 线索 A 理解边界 + 线索 B 核心链 + 文献/实验设计综合均达协议；**通过与否事后评定，本文不预设 PASSED**。
