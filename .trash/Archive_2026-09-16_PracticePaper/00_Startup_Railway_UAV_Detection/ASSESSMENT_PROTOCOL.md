# 学习评估协议（ASSESSMENT_PROTOCOL）

更新日期：2026-09-16  
适用：LEARNING-CORE 三周及并行英语模块。  
本协议要求**诚实评估**。任何文件**不得预先宣称用户已通过**；`PASSED` 只能在达标证据齐备后写入。

---

## 1. 评估原则

1. **闭卷优先**：复述、必答题、指标定义先在不看资料下完成。  
2. **证据可复查**：手算过程、结构图、只读代码标注、审计卡、运行输出截图（若有）保留路径。  
3. **初稿保留**：订正不得覆盖初稿；Progress_Log / Learning_Record 均留第一版。  
4. **AI 边界**：助手可讲解、出题、对照标准评分、指出错误类型；**禁止代填**用户复述、必答、手算与英语初稿。  
5. **科研 ≠ 英语**：英语 `PASSED` 不代替科研门；科研门不代替英语模块。  
6. **负结果诚实**：归档实验的失败/否决按原口径引用；不把书面 DISMISS 说成实测无效，反之亦然。

---

## 2. 评估手段（可组合）

| 手段 | 用于 | 助手做法 |
|---|---|---|
| 闭卷口述 | 知识链、模块边界 | 抽问节点；记录缺口 |
| 书面必答 | 每日三题等 | 对照要点评分，区分概念错/笔误 |
| 手算复查 | IoU、P/R、NMS、覆盖、参数、坐标 | 逐步核对；笔误可订正不降为“不懂”除非模式性错误 |
| 代码/输出检查 | 训练环注释、计时清单、配置字段 | 只读检查；LEARNING-CORE 默认不要求新训练日志 |
| 错误诊断 | 失效案例判断链 | 查“现象→证据→原因→决策”是否完整 |
| 文献证据 | 审计卡、claim 边界 | 查是否可追溯到篇/节，有无 overclaim |

---

## 3. 通过阈值（门槛定义，非已通过证明）

### 3.1 日检（Daily check）

当日标 `PASSED` 建议同时满足：

- 学习目标可用自己的话复述；  
- 练习证据可复查且关键步骤正确（允许少数算术笔误，概念须对）；  
- 必答题正确率 ≥ 2/3，错题有订正；  
- 自评与助手评在“能否闭卷”上无严重自欺（若助手认为不能闭卷 → `REPEAT`）。

否则：`REPEAT` 或 `REVIEWING`。未完成不作 `PASSED`。

### 3.2 周门（Weekly gate）

| 周门 | 最低要求 |
|---|---|
| W1（D07） | F1 检测链闭卷 + F4 指标手算 + F6/F7 复现或泄漏案例 |
| W2（D14） | 小目标覆盖手算 + 共享头边界（含 historical/candidate 措辞）+ 测速协议字段 |
| W3（D21） | 坐标链或 oracle 边界 + 时间预算统计量 + 实验卡可证伪 + 两线索证据边界 |

任一项不满足 → 周门 `REPEAT`：先补弱项，再进下一周核心；可并行复习，但**不降低门槛**。

### 3.3 三周终门（Final 3-week gate）

建议同时满足才可讨论“结束 LEARNING-CORE、进入 3 个月实验方案讨论”：

1. 三周门均曾达到（含补考通过）；  
2. 线索 A：能正确表述 LSM-Head 为历史候选及学其目的；  
3. 线索 B：切片/坐标、oracle、时间预算、ignore/泄漏要点可闭卷；  
4. 共同基础：YOLO 链、指标、复现清单无致命缺口；  
5. 至少 1 份可证伪实验卡 + 1 份文献迷你审计；  
6. 英语：E-R 模块无大面积 `TODO` 空置；允许部分 `REPEAT` 进入补学清单，但不造假 `PASSED`。

终门结果写入专门记录；**本文不预设通过**。

## 4. 评分量规（简表）

| 等级 | 含义 | 状态建议 |
|---|---|---|
| 掌握 | 闭卷完整 + 证据正确 + 能谈研究影响 | 可 `PASSED` |
| 部分掌握 | 主链对，细节或手算不稳 | `REVIEWING` → 定点补 |
| 未掌握 | 不能闭卷或关键概念反了 | `REPEAT` |
| 证据不足 | 只有“看过/听过” | 不得 `PASSED` |

笔误：算术错但步骤对 → 订正后可过；定义反了 → 不过。

---

## 5. 流程

```text
用户按日学习并填写 Learning_Record（初稿）
 → 助手日检（可同日或次日）
 → 写入助手评估区（不改初稿）
 → 周末周门；失败则补学清单
 → D21 终门
 → 仅当终门通过后，讨论 3 个月实验设计/执行
```

英语：模块测 + 每周检查点；CET 冲刺期另按 [English_Parallel_Plan_CET4.md](English_Parallel_Plan_CET4.md)。

---

## 6. 禁止事项

- 代填答案、直接粘贴标准复述冒充初稿  
- 无证据批量标 `PASSED`  
- 用 AI 审计 PASS 代替本人手算  
- 三周内用“已开训”证明学会（默认禁训）  
- 删改失败记录或初稿  
- 把线索 A 英语/笔记写成既定投稿方向
