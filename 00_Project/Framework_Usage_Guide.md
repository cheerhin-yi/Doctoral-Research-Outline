## 2. 当前只证明两个主张

前置论文A最多保留两个主张：

1. **主张A1**：全局校准会掩盖部分飞行条件下的可靠性退化；加入高度、云台角、目标像素尺寸、模糊度和轨道相对位置后，最差视角校准得到改善。
2. **主张A2**：条件校准风险在相同危险目标召回率下减少误报，并能输出可复现的观测有效性标志。

必须排除的反解释：

- 收益来自测试集调参或场景泄漏；
- 收益只来自更复杂模型或更多参数；
- 平均ECE改善掩盖最差视角恶化；
- 风险提升只是改变阈值或记住类别；
- 归一化轨道位置被错误宣称为物理距离。

不能改变审稿人对A1/A2判断的学习内容、实验或图表，一律删除或延后。

## 4. 每次科研会话怎么做

开始前写清楚：

1. 当前周的唯一主要交付物是什么；
2. 这次会话服务A1还是A2；
3. 结束时会留下哪个可核验文件；
4. 如果失败，如何解释而不是立即增加新模块。

结束后只更新四项：

- 实际完成内容；
- 证据路径；
- 失败或不确定点；
- 下一次30–90分钟可完成的最小动作。

没有文件、公式检查、文献证据、代码输出或实验记录的会话，不计为研究进度。

## 7. 紧凑实验故事

前置论文A只保留五个证据块：

| 块 | 回答的问题 | 优先级 |
|---|---|---|
| E0 Sanity | 数据、划分、指标和小样本校准是否正确 | MUST |
| E1 Strong baselines | 未校准、温度缩放、逻辑校准、等距回归谁最强 | MUST |
| E2 Main method | 条件校准是否改善总体和最差视角可靠性 | MUST |
| E3 Decision evidence | 相同危险Recall下误报是否降低，变量贡献是否可解释 | MUST |
| E4 Failure/polish | 场景聚类区间、失败案例和必要效率结果 | MUST |

不再增加检测器结构创新、第二条数据管线、深度集成、贝叶斯网络或复杂几何模型。随机性影响结论时才对关键配置运行3个种子；探索阶段先用一次低成本运行做继续/停止判断。

## 8. 数据和统计硬规则

- 训练、校准、测试按完整`scene_id`隔离；
- 相邻帧、同一布置重复航线和增强衍生样本不得跨集合；
- 测试集不用于拟合校准参数、选择特征、阈值或停止规则；
- 总体指标必须同时报告最差视角/条件子集；
- 置信区间按物理场景聚类计算；
- 人工布置、拍摄许可、数据许可和真实/代理变量必须记录；
- A只输出归一化位置和有效性，不输出物理侵限距离。
