# 投稿、返修与录用全过程清单

## 1. 投稿前

- [ ] 期刊Aims & Scope与题目、摘要和贡献逐条匹配；
- [ ] JIF、SCIE、最新中科院大小类分区经学校数据库核验；
- [ ] 2020、2021、2023、2024、2025预警名单核验；
- [ ] APC和学校报销政策确认；
- [ ] 数据划分、随机种子、主表和统计脚本冻结；
- [ ] 所有主张都能对应图、表或统计检验；
- [ ] 明确说明数据规模、真实独立单元和局限；
- [ ] 参考文献DOI、题目、年份和期刊逐条核验；
- [ ] 作者顺序、贡献、单位和基金信息获得全体确认；
- [ ] 图像、场地、人员和关键基础设施公开许可确认；
- [ ] 按期刊模板完成匿名、行号、图表和补充材料；
- [ ] 准备投稿信、Highlights、Graphical Abstract和建议审稿人（如期刊要求）。

## 2. 投稿归档

归档以下不可变版本：

- `manuscript_submitted.pdf`
- `cover_letter.pdf`
- `supplementary_materials.*`
- `submission_metadata.md`
- `dataset_version.txt`
- `code_commit.txt`
- `model_checksums.txt`
- 投稿系统生成的稿件编号和确认邮件。

## 3. 编辑初审

若编辑拒稿，在48小时内记录：

| 项目 | 记录 |
|---|---|
| 主要原因 | scope / novelty / evidence / language / format |
| 可修复性 | 直接改投 / 小修后改投 / 需补实验 |
| 必须修改 | 最多三项 |
| 下一期刊核验 | IF、分区、预警、范围 |
| 改投期限 | 原则上7天内 |

不得在未修改编辑指出的问题时原样改投。

## 4. 外审回复模板

每条意见使用同一结构：

| Reviewer comment | Response and rationale | Change and location | Evidence |
|---|---|---|---|
| 原文完整复制 | 先回答结论，再解释修改 | 页码、行号、图表 | 新实验或引用 |

回复原则：

- 先感谢并复述实际问题，不写空泛客套；
- 同意时说明具体修改；
- 不同意时提供数据、范围或文献证据；
- 新增实验必须进入实验注册表；
- 不能完成的要求明确说明范围和局限；
- 正文、补充材料和回复信中的数值保持一致。

## 5. 返修验收

- [ ] 所有意见均有编号并逐条回复；
- [ ] 修改稿中开启高亮或修订标记；
- [ ] 新增实验复用了冻结测试集和统计规则；
- [ ] 摘要、结论和局限随结果同步修改；
- [ ] 回复信中的页码和行号对应最终文件；
- [ ] 全体作者批准修改稿；
- [ ] 保存每轮`R1/R2`提交版本和编辑邮件。

## 6. 录用与校样

- [ ] 核对作者姓名、单位、基金、通讯作者和ORCID；
- [ ] 检查公式、单位、上下标、图分辨率和颜色；
- [ ] 检查参考文献链接和补充材料；
- [ ] 不在校样阶段新增未经审稿的结论；
- [ ] 保存录用函、校样、最终PDF、DOI和WOS收录记录；
- [ ] 将审稿意见、修改策略和失败经验写入项目复盘。

## 7. 完整录用过程的学习验收

练手论文完成的标准不只是“论文上线”，还必须能独立完成：期刊筛选、投稿系统填写、编辑沟通、回复审稿、补充实验、校样和成果归档。
