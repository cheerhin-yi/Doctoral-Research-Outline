# 前置论文B研究章程：轨道坐标对齐的双视角验证

## 1. 启动条件

本任务在前置A投稿且输出接口冻结后启动。不得为等待A录用而延迟启动，但必须使用A的冻结输出，不能边写B边改A的接口。

## 2. 固定研究问题

对于已经获得的高空首次观测和固定低空复检观测，将两次结果映射到统一轨道相对坐标并按不确定性融合，能否比单视角、概率平均和置信度加权更可靠地判断铁路隐患？

## 3. 主假设

- H1：轨道坐标一致性能够识别跨视角错误匹配和风险冲突；
- H2：逆不确定性加权融合降低遮挡、倾斜和小目标子集的危险漏判；
- H3：简单规则“高风险且首次观测无效则复检”具有可解释的筛查价值。

## 4. 输入与输出

输入：前置A冻结输出、两个视角的相机姿态、轨道边界和人工确认的跨视角目标对应。

输出：

- `object_id`
- `first_pass_risk`
- `reinspection_risk`
- `track_coordinate_consistency`
- `class_consistency`
- `fused_risk`
- `cross_view_conflict`

## 5. 方法边界

允许：轨道相对坐标投影、类别/位置/风险一致性、逆不确定性融合、固定阈值复检规则。

禁止：正式观测价值函数、时间或能耗权衡、候选视点选择、学习式复检策略、航迹规划和多无人机。

## 6. 实验矩阵

| 实验ID | 方法 | 目的 |
|---|---|---|
| B-E01 | 仅首次观测 | 单视角下界 |
| B-E02 | 仅固定低空观测 | 高质量视角参照 |
| B-E03 | 两视角概率平均 | 朴素融合基线 |
| B-E04 | 检测置信度加权 | 常用权重基线 |
| B-E05 | 所提轨道坐标＋不确定性融合 | 主方法 |
| B-E06 | 去掉坐标/类别/风险一致性 | 三项消融 |
| B-E07 | 简单复检规则 | 辅助系统实验 |

评价指标：危险Recall、FNR、AUPRC、Brier、冲突识别准确率，以及小目标、遮挡和倾斜子集结果。

## 7. 验收和降级规则

- 主方法在独立测试场景上优于首次观测和概率平均；
- 在至少两个困难子集上降低危险漏判；
- 聚类Bootstrap的95%置信区间支持主要结论。

如果简单复检规则没有稳定收益，删除其主张，只保留双视角一致性与融合；不得将正式VoI提前挪入本论文。

## 8. 交付物

- 双视角配对清单和质检报告；
- 五种融合方法结果；
- 一致性消融和困难子集表；
- 冲突案例图；
- 论文、投稿信、审稿回复矩阵和最终校样。
