# Paper 1方向校准说明

> **状态更新（2026-08-28）**：本文件定义Paper 1未来恢复后的方向，不是当前学习指南。当前唯一活动任务是前置论文A，其后为前置论文B；Paper 1主体暂停。前置A的条件校准是独立练手论文，在Paper 1中只能作为已有证据和接口，不能再把相同校准主张重复包装为RQ4创新。

## 1. 为什么需要校准

2026-08-27的新颖性审计证明：轨道中心线/边界、轨距换算、距离风险分级、铁路开放集检测和风险校准均已有近邻工作。此前为了避免重复发表，框架一度把“空间表示稳定性”提升为Paper 1主问题。这改变了原始研究方向，也削弱了YOLO学习与实验主线。

本次校准不撤销新颖性审计，而是恢复正确的主从关系：**Paper 1研究铁路无人机视觉感知；YOLO是主干；开放环境、轨道上下文、风险和可信度为感知系统服务；空间表示稳定性是支撑实验，不是论文题目。**

## 2. 当前研究内容

Paper 1暂定研究问题：

> 在铁路无人机图像的小目标、复杂背景和开放类别条件下，能否以YOLO为实时感知核心，可靠检测已知危险、补充发现未见危险候选，并利用轨道运行区域把感知结果转换为可复核的风险告警？

研究链条：

> UAV Image → YOLO Known-Hazard Detection → Unknown/Open-Vocabulary Candidate Supplement → Track Context / Intrusion Relation → Risk Alarm → Reliability / Review Queue

## 3. YOLO具体承担什么

- 学习并复现YOLO11的数据流、Backbone、Neck、Head、损失、标签匹配、增强、训练和部署指标；
- 建立YOLO11n/s/m中的最小规模对照，选择精度—速度折中；
- 系统分析铁路UAV小目标、远距离目标、细长目标、遮挡、复杂背景和高度变化下的漏检；
- 只根据失败证据选择一个最小改进方向，例如输入/切片、多尺度特征、检测头或数据增强；不同时堆叠多个模块；
- 通过消融、参数量、FLOPs、FPS、显存和跨场景结果判断改动是否值得保留；
- 作为后续未知候选、轨道风险关联和风险告警的主要已知类检测输入。

RT-DETR只作为参考或交叉验证，不与YOLO争夺主线学习时间。YOLO-World属于YOLO生态中的开放词汇补充，但其预训练和提示词条件必须与闭集YOLO11分开报告。

## 4. 四个研究问题及优先级

| 优先级 | 研究问题 | 论文角色 | 失败时处理 |
|---|---|---|---|
| P0 | RQ1：YOLO在铁路UAV危险检测中的能力、失败模式及最小适配 | 主线、必须完成 | 没有可靠基线就停止下游实验 |
| P1 | RQ2：未见危险候选能否补充YOLO闭集盲区 | 第二主线 | 误报不可控时降为讨论/附录 |
| P1 | RQ3：轨道上下文能否把检测转换为高风险告警 | 系统价值 | 只保留最简单可靠的区域/距离规则 |
| P2 | RQ4：风险概率校准能否改善人工复检排序 | 辅助验证 | 无实际收益则删除，不影响主论文 |

## 5. 不再采用的错误定位

- 不再以“哪种空间表示最稳定”作为Paper 1唯一研究问题；
- 不再要求几何H1成立后才能继续整篇论文；
- 不把RT-DETR训练安排成与YOLO同等权重的独立主周；
- 不把中心线、归一化几何、开放集检测或校准写成首次提出；
- 不为追求看似复杂而同时修改YOLO Backbone、Neck、Head和Loss。

## 6. 投稿口径决策

- 若YOLO最小改动有稳定显著收益：检测方法＋铁路应用论文；
- 若改动收益有限，但数据、开放环境协议和风险告警系统完整：应用系统/评估论文；
- 若未知候选或风险告警没有稳定作用：收缩为铁路UAV YOLO检测与失败分析论文；
- 任何口径都必须如实标注已有工作和实验边界。
