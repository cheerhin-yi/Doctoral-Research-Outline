## 第一部分：应知

### 学习目标

1. 能说出**扣件系统**里 UAV 常见可见件（扣件/弹条、螺栓螺母、垫圈等）各自干什么（工作直觉即可）。  
2. 能区分**联结件（鱼尾板/接头螺栓）**与日常扣件，并说明为何「超越扣件-only」对 Sci Data 中位重要。  
3. 能对照 Taxonomy 草稿列出：已列入族、可选族、本篇排除族；标出哪些是 **Speculation**。

### 知识链

```text
钢轨要被固定在枕上
  → 扣件系统（弹条/扣件体、螺栓螺母、垫圈…）
  → 钢轨接缝处的联结件（鱼尾板、接头螺栓）
  → 轨下基础可见件（轨距块、垫板、道钉…视线路）
  → 可选附属（标志/绝缘件等）
  → 本篇排除（接触网异物主类、人员车厢主类）
  → 与 RFDD / RailFOD23 / UAV-RSOD 的映射与重叠风险
  → 采集难度 → 发表地板/中位（见 PartFamily 文）
```

### 链上说明

1. **扣件系统（fastening）**  
   - 作用：把钢轨保持在正确位置，抵抗纵横向力。  
   - UAV 可见：金属弹条/扣件外形、螺母顶部、部分垫圈；**松脱/缺失**比「扭矩不足」更容易从外观判定。  
   - 难度：低–中；样本相对好找 → 但也最容易与 RFDD **同质**。

2. **联结件（joints）**  
   - **鱼尾板（fishplate）**：夹在两根钢轨接头外侧的夹板；接头螺栓穿过。  
   - 安全关键高；公开 UAV 方法文相对少（案头判断）。  
   - 难度：中–高；真实缺陷可能稀缺 → 允许「稀缺披露」，不硬凑。

3. **轨下基础可见件**  
   - 例：轨距块、垫板、道钉（视有砟/木枕等）。  
   - 风险：**地区与线路差异大**；写入 taxonomy 时必须可映射、可说明。

4. **可选 / 排除**  
   - 可选：轨旁标志、绝缘件等——易与异物混淆，要有协议。  
   - **排除（本篇主类）**：接触网异物、车厢/人员主类 → 属 RailFOD23 / 另一叙事；可作负例或忽略区。

5. **RFDD 重叠应对（写作必会）**  
   - RFDD：高铁扣件全景 + 计量学缺陷（近景/地面取向）。  
   - A 增量落点：**UAV 航拍尺度与视角** + **多部件族** + **标注效率/合成审计**。  
   - 摘要禁句：「首个扣件缺陷数据集」。

6. **采集难度 ↔ 发表（只记结论）**  
   - 扣件-only + 弱审计 → 工作/发表易滑向 **JCR Q3 related**（Sensors/Electronics 同档），难撑 Sci Data 中位。  
   - 多族 UAV + 真缺陷 + 双审计 → 中位瞄 **Sci Data**。  
   - 详情见 PartFamily 文；本笔记不编造 IF。
