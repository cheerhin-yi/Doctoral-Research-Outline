## 证据边界图例

| 标记 | 含义 |
| --- | --- |
| **FOUNDATION** | 写 A 前必须掌握；不构成论文 novelty |
| **HISTORICAL** | 曾作为材料或近邻已占坑；可学，不当作「我们首创」 |
| **CANDIDATE** | 可讨论、可被实验证伪的结构/类目/协议；**尚未冻结** |
| **ARCHIVED_EVIDENCE** | 案头已写明的近邻事实（含「已占坑」）；可引用划界，≠ 本篇已成立 |
| **VALIDATED_PROTOCOL** | 已核验的程序（授权后才可能出现）；学习阶段多为草稿 |
| **BLOCKED / HOLD / IDLE** | 未获准执行；学习阶段不擅自采集/训练/主 Run |
