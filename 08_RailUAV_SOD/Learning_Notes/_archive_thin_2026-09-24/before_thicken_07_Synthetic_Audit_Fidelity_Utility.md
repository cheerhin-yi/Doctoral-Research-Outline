## 第一部分：应知

### 学习目标

1. 能区分「生成了更多图」与「合成在给定比例下是否提升效用且 fidelity 可披露」。  
2. 能默写披露清单关键字段（生成器类型、版本种子、域、比例、混测、伪影、许可等）。  
3. 能说明默认**合成不进 test**，以及曲线无增益时如何收缩主张。

### 知识链

```text
真实缺陷稀缺
  → 合成补量诱惑
  → 近邻已堆合成（RailFOD23 等）
  → 本篇改卖审计：披露字段 + fidelity–utility 曲线
  → 横轴合成占比 / 纵轴封闭集指标
  → 对照：仅真实 / 真实+合成 /（慎）仅合成
  → 稀缺真实类上增益是否消失
  → 失败：无增益或无法诚实披露 → 缩小合成主张
```

### 披露字段（投稿前必填意识）

| 字段 | 问什么 |
|---|---|
| 生成器类型 | 渲染 / 拷贝粘贴 / 风格迁移 / 扩散 / 其他 |
| 版本与种子 | 可复现 |
| 源域/目标域 | 是否含真实缺陷纹理 |
| 合成比例 | train 占比；val/test 是否含 |
| 类别覆盖 | 哪些 part×defect 依赖合成 |
| 混测声明 | 默认否 |
| 已知伪影 | 光照、边缘、重复纹理… |
| 许可 | 源资产能否再分发 |

### 练习

1. 写一段与 RailFOD23 的划界句（不贬低对方，只定位增量）。  
2. 假设曲线在 25% 合成处升、50% 处降：你在 Data Records / 讨论里怎么写？  
3. 列出 2 个「合成刷分」红旗（评价协议被污染的方式）。

### 必答题

1. fidelity 与 utility 各回答什么问题？二者为何可能打架？  
2. 为什么「合成进了 test」会伤害数据文可信度？  
3. 曲线无增益时，正确的主张收缩是什么（而不是改指标粉饰）？

### 当前边界

- 清单 DRAFT · IDLE；无授权不生成大规模合成主证据。  
- 不把合成缺陷称为现场真实缺陷。
