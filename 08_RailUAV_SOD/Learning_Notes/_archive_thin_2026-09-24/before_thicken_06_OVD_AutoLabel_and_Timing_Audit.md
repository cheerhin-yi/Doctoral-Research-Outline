## 第一部分：应知

### 学习目标

1. 能说明双引擎（文本提示 + 视觉提示）在本篇中的角色与失败模式。  
2. 能复述 D4 式受控计时：从零 vs 预标注+修正，以及加速比、接受率、修错率、Kappa、误差模式。  
3. 能列出至少三条「禁止写法」（未受控体感加速、用测试集调提示不披露、把告警指标当 A 主结果）。

### 知识链

```text
封闭集标注成本高
  → OVD/开词表检测器作预标注
  → E1 文本提示 + E2 视觉提示（抑制歧义）
  → 输出：框 + 引擎 ID + 提示词版本哈希
  → 人工修正
  → 与从零标注对照（顺序平衡）
  → 人时/实例、接受率、修错率、Kappa、误差模式
  → 主张：受控效率可审计（不是「又一条管线」）
```

### 链上说明

1. **相对 DART**  
   - DART 已展示 DreamBooth+Grounding DINO 类半自动管线。  
   - A **不卖管线发明**；卖的是受控人时/质量曲线与误差模式表。

2. **主指标（A）**  

| 指标 | 用途 |
|---|---|
| 时间/实例 | 加速比核心 |
| 接受率 | 预标注可用性 |
| 修错率 | 成本 |
| Cohen's Kappa | 一致性 |
| 误差模式计数 | 漏检/过检/错类/框漂移 |

3. **不是 A 主指标**  
   - 固定告警预算下的危险召回、风险排序 AUPRC、可派发队列 → **B**。

4. **提示词与泄漏**  
   - 在 test 上调提示词后不披露 → 无效审计。  
   - 术语表/Prompt 五元组可与 B 共享资产，但本篇只报**标注侧**影响。

### 练习

1. 画 D4 流程：子集冻结 → 培训 → 条件 A/B → 录时 → 抽检 → 出表。  
2. 设计一行「误差模式」记录字段（至少 4 类）。  
3. 改写一句违规宣传语为合规句（原稿含「显著提升开放世界告警召回」）。
