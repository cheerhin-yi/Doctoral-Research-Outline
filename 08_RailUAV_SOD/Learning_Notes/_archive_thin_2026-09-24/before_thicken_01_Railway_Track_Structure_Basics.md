## 第一部分：应知

### 学习目标

1. 能用自己的话指出一张俯视/斜视轨道图里：**钢轨、轨枕、道床（有砟或板式）**分别是什么。  
2. 能解释**轨距**为何让钢轨成对出现，以及 UAV 图上如何粗辨左右股。  
3. 能列出至少三类「**UAV 主相机通常看不见 / 不该进本篇主类**」的东西，并说明为什么。

### 知识链

```text
轨道在地面上长什么样
  → 钢轨（承载与导向）
  → 轨枕（固定间距、承托钢轨）
  → 道床：有砟（石砟）或板式/无砟
  → 轨距（两股钢轨内侧间距）
  → UAV 俯视/斜视能看到的层
  → 本篇要检测的「小部件」落在哪一层
  → 哪些缺陷只能接触式/内部检测 → 排除或稀缺披露
```

### 链上说明（非标准定义，工作直觉）

1. **钢轨（rail）**  
   - 两条纵向金属条，列车车轮在其上滚动。  
   - UAV 图里通常是两条平行亮/暗线；接头、焊缝、表面伤损是否可见取决于航高与分辨率。  
   - 本篇主叙事是**小部件×缺陷**，不是「再做一个轨面伤损大数据集」（近邻已有 RSD_UAV 等轨面取向工作 → 划界见 `05`）。

2. **轨枕（sleeper / tie）**  
   - 横放在钢轨下方，把荷载传到道床；常见混凝土枕或木枕。  
   - UAV 下视可见枕的间距纹理；**扣件就装在轨枕与钢轨相交处附近**。

3. **道床：有砟 vs 板式（slab）**  
   - **有砟**：钢轨–枕下是碎石道砟，纹理杂乱，小部件易被石子/阴影干扰。  
   - **板式/无砟**：混凝土道床更「干净」，扣件排列更规整，但反光/接缝可能造成假缺陷。  
   - 写作时：线路类型要进场景元数据；**不要**假设全世界都是同一种道床。

4. **轨距（gauge）**  
   - 两股钢轨**内侧**之间的名义间距（具体数值因国家/线路标准而异 → 本笔记**不背诵未核验数字**；需要时查已引标准原文）。  
   - 对检测：模型常看到「一对平行轨 + 中间道床」；左右股部件应对称出现，**单侧缺失**往往是强缺陷线索。

5. **UAV 能看见什么（本篇默认）**  
   - 可见：轨面轮廓、枕、道床纹理、**扣件族/接头族/轨距块等外露金属或塑料件**、宏观缺失/错位/大块腐蚀剥落。  
   - 通常不可见或不可靠：轨头内部裂纹、强栓预紧力、需敲击/探伤的伤损、被道砟完全掩埋的件。  
   - 规则：**看不见就不要放进主 mAP 类**；若偶发可见，标「稀缺披露 / 可选」。

### 练习

1. 自绘一张「轨横切」简图，标注：钢轨、扣件位置示意、轨枕、道床。不必专业制图。  
2. 对照（或想象）一张铁路 UAV 俯视图：指出左右股、枕间距方向、扣件大概落点。  
3. 写出 3 个「不进本篇主类」的例子，并各用半句话说明原因（接触式 / 属异物另一叙事 / 内部不可见）。

### 必答题

1. 有砟与板式在 UAV 图上对「小部件检测」各有什么主要干扰？  
2. 为什么「轨距」对「缺失类缺陷」标注有帮助？  
3. 若某缺陷必须拆开扣件或用探伤仪才能确认，本篇应如何处理该类？（主类 / 可选 / 排除）
