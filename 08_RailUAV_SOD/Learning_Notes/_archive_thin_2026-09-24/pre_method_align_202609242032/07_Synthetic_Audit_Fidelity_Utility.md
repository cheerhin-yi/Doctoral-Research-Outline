## 第一部分：应知

### 学习目标

1. 能区分「生成了更多图」与「合成在给定比例下是否提升效用且 fidelity 可披露」。  
2. 能默写披露清单关键字段（生成器类型、版本种子、域、比例、混测、伪影、许可等）。  
3. 能说明默认**合成不进 test**，以及曲线无增益时如何收缩主张。  
4. 能写一句与 RailFOD23 的划界句（不贬低对方）。

### 知识链

```text
真实缺陷稀缺
  → 合成补量诱惑
  → 近邻已堆合成（RailFOD23 等）
  → 本篇改卖审计：披露字段 + fidelity–utility 曲线
  → 横轴合成占比 / 纵轴封闭集指标
  → 对照：仅真实 / 真实+合成 /（慎）仅合成
  → 稀缺真实类上增益是否消失
  → 失败：无增益或无法诚实披露 → 缩小合成主张
```

### 通俗讲解：合成是「药」，要写剂量和副作用

#### 1. fidelity 与 utility 可能打架

- **fidelity 问：** 合成样本是否像真实 UAV 铁路域（外观、噪声、尺度）？  
- **utility 问：** 加进 train 后，封闭集指标或稀缺类召回是否提升？  
- **打架例：** 很好看的生成图（高保真感）却让模型学到生成器伪影，真实 test 下降；或「脏」的拷贝粘贴反而提升效用。  
- 数据文要**两条都报**，不能只晒漂亮图。

#### 2. 披露字段（投稿前必填意识）

| 字段 | 问什么 |
|---|---|
| 生成器类型 | 渲染 / 拷贝粘贴 / 风格迁移 / 扩散 / 其他 |
| 版本与种子 | 可复现 |
| 源域/目标域 | 是否含真实缺陷纹理 |
| 合成比例 | train 占比；val/test 是否含 |
| 类别覆盖 | 哪些 part×defect 依赖合成 |
| 混测声明 | 默认否 |
| 已知伪影 | 光照、边缘、重复纹理… |
| 许可 | 源资产能否再分发 |

完整清单见 `Synthetic_Disclosure_Checklist.md`。

#### 3. 默认合成不进 test

若合成进了 test：你在测「识别自己的生成器」，数据文可信度受伤。若例外允许，必须在披露清单**显式标明**并单独报表。

#### 4. 曲线怎么读（主张收缩）

- 横轴：train 中合成占比；纵轴：同协议封闭集指标（可另附稀缺真实类 Recall）。  
- 25% 升、50% 降 → 报告最优点与下降，**不要**只截上升段。  
- 无增益 → 缩小合成主张（「探索性补充」），或去掉合成主贡献，回到真实数据+效率审计。

#### 5. 相对 RailFOD23 的划界意识

对方可以「大量合成」；你卖「比例–性能可审计 + 字段级披露 + 默认不混测」。不贬低，只定位增量。

| 禁止 | 改法 |

| 合成进 test 不声明 | 默认禁止；例外必披露 |

### 参考答案

#### 练习 1 参考

「相对以大量合成为主叙事的接触网异物基准，本工作在轨道小部件外观缺陷设定下，提供合成比例–封闭集性能曲线与字段级披露，并默认合成不进入测试集。」

#### 练习 2 参考

报告 25% 为观测最优点，披露 50% 下降；讨论过拟合伪影或类不平衡；不把 50% 结果静默删除。

#### 练习 3 参考

（1）test 混入合成却与真实混报同一 mAP；（2）只在合成很多的类上宣称 SOTA，稀缺真实类 Recall 隐藏不报。

#### 必答 1 参考

fidelity=像不像目标域；utility=是否提升真实评价。可打架：像却学伪影，或不太像却仍有用。

#### 必答 2 参考

测试变成识别生成器分布，高估可部署到真实走廊的性能，违反数据文「可复用基础设施」承诺。

#### 必答 3 参考

缩小或撤销「合成提升效用」主主张；保留真实数据基准与（若有）效率审计；诚实写「合成无增益」。

### 补充课：比例–性能曲线怎么画才算「审计」

```text
横轴：train 中合成占比（0% / 10% / 25% / 50% …）
纵轴：同协议封闭集主指标（可另附稀缺真实类 Recall）
对照：仅真实；真实+合成；慎用仅合成→真实 test
纪律：默认合成不进 test；例外必须单独报表
```

若 25% 升、50% 降：两段都要写，不允许只截上升段。无增益：收缩主张，不要改指标粉饰。

### 补充课：与 RailFOD23 划界的「不贬低」模板

「相对以大量合成为主叙事的接触网异物基准，本工作在轨道小部件外观缺陷设定下，提供合成比例–性能曲线与字段级披露，并默认合成不进入测试集。」


### 补充课：fidelity 代理分数的位置

FID/KID、人工迫选、检测器合成→真实落差，都只是代理。它们**不能**替代真实 test 上的 utility 曲线。高保真感却掉真实指标，是经典打架案例，必须两轴同报。

稀缺真实类：Data Records 必须并列「真实计数 / 合成计数」，禁止把合成补量写成「大规模真实已覆盖」。


### 补充课：三类 train/test 对照（再强调）

| 对照 | train | test | 目的 |
|---|---|---|---|
| 仅真实 | 真实 | 真实 | 地板 |
| 真实+合成 | 真实∪合成 | 真实 | 效用主曲线 |
| 仅合成（慎） | 合成 | 真实 | 看域间隙 |

禁止主结果用「合成 train + 合成 test」。

### 补充课：伪影检查最小清单

边缘缝、阴影方向不一致、重复贴片、分辨率突变、类别共现不合理（如鱼尾板悬浮无轨缝）。每条记录：已观察？缓解？是否仍进 train？


### 边界重申

披露清单 DRAFT · IDLE；无授权不生成大规模合成主证据。不把合成缺陷称为现场真实缺陷。曲线无增益时收缩主张，不粉饰指标。

### 与 Taxonomy 稀缺披露的接口

某 part×defect 真实样本过少时，允许合成补 train，但 Data Records 必须分列真实/合成计数；主文不得写成「大规模真实已覆盖」。


学习口诀：合成是药，写清剂量与副作用；默认不混测；无增益就收缩主张。


### 再练：两句主张收缩

1. 有增益：「在真实测试集上，合成占比约 X% 时封闭集指标相对仅真实提升，并报告伪影与类覆盖。」  
2. 无增益：「合成未显示稳定效用；本文收缩合成主张，保留真实基准与披露字段。」

### 补充：三类对照怎么设（学习版）

| 对照 | train | test | 目的 |
|---|---|---|---|
| 仅真实 | 真实 | 真实 | 地板 |

### 补充：伪影清单怎么写才像审计

至少覆盖：边缘缝、阴影方向不一致、重复纹理贴片、分辨率突变、类别共现不合理（例如鱼尾板悬浮无轨缝）。每条给「是否已观察 / 缓解措施 / 是否仍进入 train」。

### 补充：稀缺真实类的并列披露

若总体 mAP 因合成上升，但某一真实稀缺 part×defect 的 Recall 不升或下降：主文必须并列披露，不能只报总体。这是数据文诚实性的核心之一。


### 补充：fidelity 的可操作代理（不必一次全做）

可选代理（标 Speculation/待冻结）：FID/KID（慎用于小域）、人工迫选「真假」、关键视觉检查表通过率、检测器在合成→真实的性能落差。  
**纪律：** 代理分数不能替代「真实 test 上的 utility 曲线」。

### 补充：与 Taxonomy 稀缺披露的衔接

某 part×defect 真实样本 < N（N 冻结时定）：允许合成补 train，但 Data Records 必须写「真实计数 / 合成计数」；主文不得把该类写成「大规模真实缺陷已覆盖」。
