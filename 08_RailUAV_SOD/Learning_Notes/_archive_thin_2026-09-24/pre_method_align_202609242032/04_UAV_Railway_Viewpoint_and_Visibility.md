## 第一部分：应知

### 学习目标

1. 能解释航高、云台角（下视/斜视）、地面采样距离（GSD）如何改变小部件的像素覆盖。  
2. 能说明 UAV 航拍相对 RFDD 类**近景/地面扣件影像**的硬差异（写作用）。  
3. 能描述遮挡、运动模糊、道砟纹理如何造成「尺度断崖」与不可标区域。  
4. 能做符号级估算：\(L/g\) 像素跨度，并反推可标 GSD 上限。

### 知识链

```text
飞行平台与航高
  → 云台角：下视 / 斜视
  → GSD（每像素对应地面尺寸）
  → 小部件关键尺寸占多少像素
  → 低于可标阈值 → 漏检或 D5
  → 遮挡（车、影、砟、邻近设备）
  → 与近景数据集的视角差异（划界）
  → 场景/航次隔离（防泄漏）
```

### 通俗讲解

#### 1. GSD：像素是「尺子上的一格」

- **机制：** GSD 表示地面上多大长度被压进一个像素。部件特征长度 \(L\)、GSD 为 \(g\) 时，像素跨度近似 \(L/g\)（理想针孔、近似水平地面；斜视还要考虑投影，学习阶段先掌握这一阶）。  
- **类比（辅助）：** 站得越高，照片里同一颗螺母占的格子越少；格子太少，标注员只能猜 → 应标 D5 或干脆不进主类。  
- **草案航高（Unknown/待核验）：** Collection 草稿曾写相对轨面约 15–40 m 量级——**待现场核验，学习阶段当作量级直觉，不虚构已测 GSD**。

#### 2. 下视 vs 斜视

| | 下视 | 斜视 |
|---|---|---|
| 几何 | 左右股更对称 | 透视：近大远小 |
| 部件外观 | 顶面为主（螺母顶、弹条顶视） | 侧面轮廓有时更清楚（弹条弯钩、鱼尾板厚度） |
| 风险 | 顶视特征弱时难辨型号 | 尺度断崖更剧；远距端易不可标 |
| 对 RFDD 划界 | 强调「航拍尺度」 | 强调「航拍视角 ≠ 近景手持」 |

#### 3. 尺度断崖（scale cliff）

同一航带：近端弹条 20+ px 可标，远端只剩 3–4 px → 若强行标 D1/D2，标签噪声会毁基线。  
**纪律：** 冻结「最小可辨像素」；低于阈值 → D5/忽略，而不是赌标注员眼神。  
与 Practice 小目标笔记相通：评价应回到**原图尺度**协议，不能只看网络输入 `imgsz`。

#### 4. 遮挡与质量 → D5/忽略

列车占画面、接触网投影、人员、道砟掩埋、积水反光、运动模糊：按协议进 D5 或忽略区（`03`）。Data Records 预声明哪些条件排除出主评价。

#### 5. 「UAV 硬切」相对 RFDD 指什么

不是口号，而是可核对差异：**传感器距离与视角（航拍 vs 近景）、目标像素尺度分布、场景运动与遮挡统计、线路走廊背景**。写划界句时点这些，而不是只写「我们也是扣件」。

#### 6. 泄漏

近邻帧、同航次切片同时进 train 与 test → 封闭集 mAP 虚高。原则（预声明）：场景/航次/线路隔离（Taxonomy §5）。学习阶段会复述即可，不跑划分脚本冒充已完成。

### UAV 能看清的条件（清单意识）

| 条件 | 可标倾向 | 不可标倾向 |
|---|---|---|
| 像素跨度 ≥ 协议下限 | 是 | 否 → D5 |
| 无严重运动模糊 | 是 | 否 |
| 部件外轮廓对比足够 | 是 | 阴影/反光淹没 → D5 |
| 未被列车/砟完全挡住 | 是 | 否 |

### 常见错误 / 禁止说法

| 禁止 | 原因 | 改法 |
|---|---|---|
| 「把 imgsz 提到 1280 就解决航高问题」 | 输入尺寸≠地面可辨信息；模糊/欠采样不能靠插值恢复物理细节 | 先控航高/GSD与可标阈值 |
| 把草稿航高写成已测事实 | 未授权未核验 | 标草案/Unknown |
| 「UAV 与 RFDD 同类近景」 | 抹掉硬切 | 写尺度与视角差异 |
| 同航次泄漏还不披露 | 指标造假风险 | 场景隔离 + 披露 split 哈希 |

### 参考答案

#### 练习 1 参考

要求 \(L/g \ge 8\) ⇒ \(g \le L/8\)。若 \(L=4\,\mathrm{cm}=0.04\,\mathrm{m}\)，则 \(g\le 0.005\,\mathrm{m/px}=0.5\,\mathrm{cm/px}\)。（数字为演算示例，**不是**现场已测值。）

#### 练习 2 参考

近景手持：部件可占图像大部，背景简单，计量学细节可见。UAV 斜视：走廊背景复杂，部件占像素少，透视尺度变化大——审稿人会视为不同成像任务，不能当同一近景扣件集。

#### 练习 3 参考

列车占满；道砟掩埋扣件；强阴影/接触网投影；运动模糊；积水镜面（任列 3 个即可）。

#### 必答 1 参考

航高过高时，光学信息在采样阶段已丢失（GSD 过大/模糊）；增大网络输入尺寸只是把已有像素拉大，不能恢复未采集到的高频细节。

#### 必答 2 参考

指航拍距离与视角、像素尺度分布、遮挡与运动统计等与近景扣件影像可核对的差异，并据此写增量，而不是重复 RFDD 的近景扣件全景设定。

#### 必答 3 参考

近邻帧泄漏会使模型「记住」同一走廊片段，test mAP 虚高，Technical Validation 无法证明泛化到新场景。

### 补充课：用「尺子」而不是感觉谈可见性

UAV 铁路成像里，最容易犯的错是用「我觉得清楚」代替可复核的尺子。

1. **先问 GSD，再问类名。** 若弹条特征长度约 4–8 cm，而 GSD 已到 1 cm/px，弹条在图上可能只占几个像素；这时再谈 D2「裂纹」没有操作意义。  
2. **斜视不是免费增益。** 斜视能露出侧面轮廓，但也把同一航带撕成「近端可标、远端不可标」两半；Data Records 里应分桶统计可标率。  
3. **硬切句要可核对。** 「UAV 硬切相对 RFDD」不是口号，而是：距离、视角、像素尺度分布、走廊背景与运动遮挡统计——写进划界段，让审稿人能对照。  
4. **泄漏比模型更致命。** 同航次近邻帧跨 train/test，封闭集 mAP 会虚高；学习阶段就要会复述隔离原则，授权后才能写 split 哈希。

### 补充课：可标阈值的诚实写法（草案意识）

```text
若实例在原图上的短边像素 < T  → 标 D5 或忽略，不进主 mAP
T 按道床类型（有砟/板式）与视角（下视/斜视）分桶报告
T 的具体数字未现场核验前标 Unknown，禁止写成已测国标
```

### 补充：有砟 vs 板式在视角上的连锁效应

- 有砟：纹理噪声高 → 同样 GSD 下「可标」更苛刻（对比度差）。  
- 板式：对比可能更好，但斜视反光条带会造成假边缘。  
- 因此「可标阈值」最好按**道床类型**分开报告，而不是只给一个全球 \(T\)。
