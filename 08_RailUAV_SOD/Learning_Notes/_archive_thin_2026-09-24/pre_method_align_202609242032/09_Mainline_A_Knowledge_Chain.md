## 第一部分：应知

### 学习目标

1. 能闭卷串讲从「铁路可见结构」到「Sci Data 披露」的完整链，并在分叉处标 BOUNDARY 词。  
2. 能指认 A-C1 / A-C2（PROPOSED）各需要什么证据，以及哪些证据属于 B 不得写入。  
3. 能完成「删掉对 B 的全部引用后，主表与贡献句是否仍完整」自检。  
4. 能在自采受阻时写出降档路径，且**禁止**「把 A 塞进 B」。

### 知识链（主链）

```text
铁路 FOUNDATION（01–03）
  → UAV 可见性与尺度断崖（04）
  → 近邻划界与 Sci Data 工艺 / venue 梯子（05）
  → Taxonomy 两轴冻结（案头 DRAFT→未来 A1）
  → 双引擎 OVD 预标注 + D4 人时审计（06）
  → 合成 fidelity–utility 披露与曲线（07）
  → 封闭集同协议基线表（08）
  → Data Records + Technical Validation
  → 中位 Sci Data；弱则 JCR Q2/Q3 related；失败则暂缓
  ※ 全程不进入：告警预算 / 风险排序（B）
  ※ 全程 BLOCKED：未授权采集/训练
```

### 参考答案

#### 练习 1 参考

链上依次：01–03 结构与缺陷 → 04 可见性 → 05 工艺/梯子 → taxonomy → 06 D4 → 07 合成 → 08 基线 → Data Records/Validation → venue；在 A2 采集处标 **BLOCKED until Current_Stage**；旁路标 B 告警禁入。

#### 练习 2 参考

左：mAP、稀缺 Recall、人时/实例、Kappa、合成曲线点。右：预算下危险召回、风险 AUPRC、可派发队列指标等。

#### 练习 3 参考

「我们发布 UAV 视角多部件铁路外观缺陷基准，并提供预标注人时与合成比例的可审计协议与封闭集基线。」——无 alarm/budget。

#### 练习 4 参考

优先：缩族 + 保协议 → JCR Q2/Q3 related；或 Data in Brief/技术报告；或暂缓。**明确写：不把 A 并入 B。**

#### 必答 1 参考

主张大意：UAV×铁路小部件×真实缺陷可复用基准 + 封闭集基线（+审计）。防同质短语：**UAV 视角 / 多部件（非扣件-only）/ 审计**。

#### 必答 2 参考

提示词等资产可共享以省工程；但 A 主结果是标注效率与数据质量，B 主结果是告警/风险——混用会破坏独立发表与审稿焦点。

#### 必答 3 参考

唯一 ACTIVE=`P0_EI`。Learning_Notes 填满**不**改变它。
