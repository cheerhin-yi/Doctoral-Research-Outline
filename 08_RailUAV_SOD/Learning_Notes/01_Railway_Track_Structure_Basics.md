## 第一部分：应知

### 学习目标

1. 能用自己的话指出一张俯视/斜视轨道图里：**钢轨、轨枕、道床（有砟或板式）**分别是什么，以及它们谁在谁上面。  
2. 能解释**轨距**为何让钢轨成对出现，以及 UAV 图上如何粗辨左右股；理解「单侧缺失」为何是强缺陷线索。  
3. 能列出至少三类「**UAV 主相机通常看不见 / 不该进本篇主类**」的东西，并说明机制原因（不是空话「太难」）。  
4. 能把「本篇要检测的小部件」落到正确结构层：多数在**钢轨–轨枕相交处附近的外露件**，不是整条钢轨本身。

### 知识链（可闭卷复述）

```text
轨道在地面上长什么样
  → 钢轨（rail）：两条纵向金属条，车轮在上面滚
  → 轨枕（sleeper/tie）：横放，固定间距，承托钢轨并把力往下传
  → 道床：有砟（碎石）或板式/无砟（混凝土板）
  → 轨距（gauge）：两股钢轨内侧名义间距 → 成对、对称
  → UAV 俯视/斜视能看到的「层」
  → 本篇小部件（扣件等）落在哪一层
  → 哪些缺陷只能接触式/内部检测 → 排除或稀缺披露
```

### 通俗讲解：把轨道想成「可分层的地面机器」

把铁路想成一台铺在地面上的长机器。它要干两件事：**(1) 让车轮沿固定路线滚；(2) 把车的重量一层层传到大地**。UAV 航拍看到的，主要是这台机器**最上面几层的外观**。

#### 1. 钢轨（rail）——「轮子滚的两条金属条」

- **机制（字面）：** 两条纵向平行的钢轨，车轮踏面在轨头顶面滚动；轮缘靠钢轨内侧导向。钢轨本身把荷载与导向力往下传到轨枕与扣件。  
- **类比（只辅助，不替代机制）：** 像两条很长的「金属导轨」；但真正受力路径是「轮 → 轨 → 扣件/枕 → 道床 → 地基」，不是「两条轨自己悬空」。  
- **UAV 俯视/斜视长什么样：**  
  - 俯视：两条近似平行的亮线或暗线，中间是道床纹理。  
  - 斜视：能看到轨头侧面一点轮廓，接头夹板（鱼尾板）有时更明显（详 `02`）。  
  - 高航高时：整条轨还看得见，但轨上的**小螺母/弹条**可能只剩几个像素（`04` 尺度断崖）。  
- **本篇检测焦点：** 不是「再做一个轨面伤损大数据集」（近邻已有 RSD_UAV 等轨面取向 → 划界见 `05`），而是轨旁**小部件 × 外观缺陷**。

#### 2. 轨枕（sleeper / tie）——「横着垫在钢轨下面的梁」

- **机制：** 轨枕按大致固定间距横放；钢轨坐在枕上（经垫板/扣件）；枕把力分散到道床。  
- **UAV 可见：** 俯视常见「梯子」纹理——纵向两股轨 + 横向一排排枕。枕间距在图上是重复图案，有助于模型建立「部件应出现在交点」的先验。  
- **和扣件的关系：** **扣件就装在「钢轨与轨枕相交处附近」**。找扣件，先找交点，不要在道床中间乱找。

#### 3. 道床：有砟 vs 板式（slab）——「枕下面垫什么」

| 类型 | 机制 | UAV 图上长什么样 | 对小部件检测的干扰 |
|---|---|---|---|
| **有砟** | 枕下是一层碎石（道砟），靠石子咬合与弹性支承 | 中间道床纹理杂乱、颗粒感强；阴影多 | 石子边、阴影易被当成「小金属件」；缺失件可能被石子部分掩埋 |
| **板式/无砟** | 混凝土板等代替碎石；几何更「干净」 | 中间更平整、色块更均匀；扣件排列往往更规整 | 反光、接缝、模板痕迹可能造成假裂纹/假缺失；脏污对比更刺眼 |

- **写作纪律：** 线路类型必须进**场景元数据**（有砟/板式/混杂）。**不要**假设全世界都是同一种道床，也不要用「高铁=一定无砟」这种未核验断言当全域前提。  
- **Speculation：** 具体某条线路属于哪种，以许可采集后的现场记录为准；学习阶段只建立「两类都会出现」的意识。

#### 4. 轨距（gauge）——「为什么总是成对、而且大致对称」

- **机制：** 两股钢轨**内侧**之间保持名义间距，车轮才能正确落在两条轨上并导向。具体毫米数因国家/线路标准而异 → **本笔记不背诵未核验数字**。  
- **对检测的字面用途：**  
  1. 图上通常看到「一对平行轨 + 中间道床」；左右股部件**应对称出现**。  
  2. **单侧缺失**（左边有弹条、对称位置右边没有）往往是比「孤立小斑点」更强的缺陷线索。  
  3. 若模型把「一整段单轨」当正常，多半是数据里缺乏成对约束或标注协议没写清左右股。  
- **自检口诀：** 看见一对轨，先问「对称位置该有的件还在吗？」再问「单侧异常是真缺失还是被遮挡（D5）？」

#### 5. UAV 能看见什么 vs 看不见什么（本篇默认）

**通常可见（可进主类候选）：**

- 轨面轮廓、轨枕间距纹理、道床大纹理（有砟/板式可辨）。  
- **外露**扣件族外形、螺母顶部、部分垫圈、鱼尾板外轮廓、宏观缺失/错位/大块腐蚀剥落。  
- 列车、接触网影子等造成的**遮挡区域**（应标 D5 或忽略，而不是硬猜缺陷）。

**通常不可见或不可靠（排除或稀缺披露）：**

| 例子 | 为什么 UAV 主相机不行 | 本篇处理 |
|---|---|---|
| 轨头内部裂纹、需要探伤的伤损 | 内部或需专用仪器；外观无开口时看不见 | **排除**主 mAP；勿冒充已探伤 |
| 螺栓预紧力 / 扭矩不足 | 力是力学量，不是外观类；外观可能仍「看起来拧着」 | **排除**主类；勿写「力矩不合格」无测量依据 |
| 被道砟完全掩埋的件 | 光学看不到 | D5 / 忽略 / 稀缺披露 |
| 接触网异物、车厢人员主类 | 属另一叙事（RailFOD23 等） | **排除主类**；可作负例（见 `02`） |

**规则（记住）：** **看不见就不要放进主 mAP 类**。偶发可见 → 标「稀缺披露 / 可选」，并在 Data Records 写清样本量。

### UAV 视角下「横切」心智模型（自绘用）

从上到下（俯视时你主要看到最上面）：

```text
[相机]
   ↓
钢轨顶面 / 轨头外轮廓
   ↓
扣件外露件（弹条、螺母顶…）← 本篇 SOD 主战场
   ↓
轨枕顶面纹理
   ↓
道床（石砟颗粒 或 混凝土板）
```

斜视时多看到一点**侧面**：弹条弯钩轮廓、鱼尾板侧面厚度更容易露出来，但远近尺度差更大（`04`）。

### 常见错误 / 禁止说法

| 禁止或慎用 | 为什么错 | 应改成 |
|---|---|---|
| 「轨距就是两轨中心距」 | 名义轨距通常指**内侧**间距 | 「两股钢轨内侧名义间距（数值查已引标准）」 |
| 「无砟一定比有砟好检」 | 机制不同：无砟更干净但反光/接缝假缺陷也多 | 「各有干扰类型；写入场景元数据」 |
| 「UAV 能替代探伤」 | 探伤看内部；UAV 看外观 | 「UAV 只做外观可分辨的小部件×缺陷」 |
| 「我们做了轨面伤损全集」 | 与 RSD_UAV 等近邻叙事易撞；且非本篇主轴 | 「小部件×缺陷；轨面取向工作另划界（`05`）」 |
| 编造未引用的国标号/轨距毫米当事实 | 违反诚实披露 | 标 Unknown 或查已引原文 |

### 参考答案（自学核对用；第二部分仍请你自己默写）

#### 练习 1 参考

自上而下应能标出：钢轨截面（或顶面示意）→ 扣件外露件画在轨–枕交点附近 → 轨枕横梁 → 道床（有砟画碎点；板式画平整层）。若扣件画在道床正中央且远离钢轨，说明「交点」直觉未建立 → 重画。

#### 练习 2 参考

- 左右股：两条纵向平行线。  
- 枕间距方向：垂直于钢轨的重复条带。  
- 扣件落点：每条轨与每根枕的交点附近（通常每交点一组）。不要指到两轨正中间的道床中心当扣件。

#### 练习 3 参考（示例，你的例子可不同但机制要对）

1. 轨头内部裂纹 —— 内部伤损，光学主相机不可见 → **排除**或仅稀缺披露且不得冒充探伤。  
2. 螺栓预紧力不足 —— 力学量，外观可能仍完整 → **排除**主类。  
3. 接触网挂异物 —— 属 RailFOD23 类异物叙事 → **排除主类**（可作负例）。

#### 必答 1 参考

- 有砟：碎石纹理与阴影易伪阳性；部件可能被石子部分掩埋导致漏检或被迫标 D5。  
- 板式：几何更干净、排列更规整，但混凝土反光、板缝、脏污对比可能造成假裂纹/假缺失。  
- 两者都要进场景元数据，不能假设单一道床。

#### 必答 2 参考

轨距约束使左右股部件应对称出现；标注与质检时可做「对称位置对照」。单侧缺失比孤立噪声斑点更像真缺陷；也有助于发现漏标（一边标了缺失、对称边却漏标正常件）。

#### 必答 3 参考

应 **排除出主 mAP 类**（或极严格条件下「稀缺披露/可选」且样本量诚实披露）。因为标签无法由 UAV 外观稳定复现，硬进主类会引入不可审计噪声，并暗示你做了接触式/探伤确认——本篇默认没有。
