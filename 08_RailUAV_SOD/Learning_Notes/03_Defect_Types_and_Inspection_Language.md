4. 如果这里出错，最终会出现什么可观察现象？

## 📚 按结构填写知识链

**工作码表（候选 · 待冻结）：** D0 正常｜D1 缺失｜D2 可见断裂/裂纹｜D3 松脱/位移｜D4 宏观腐蚀/剥落｜D5 遮挡/不可判定（质量类，通常不进主 mAP）

### 1. 为什么要 part × defect

- **机制：** 同一物理位置的「弹条」可以是完好（D0）、整件不见（D1）、歪了（D3）。若只用一个「坏弹条」标签，无法回答缺了多少、歪了多少、正常对照有多少。
- **数据文需要：** 可复现的外观操作定义 + 可分的评价轴。
- **类比：** 存货盘点——先认零件，再认状态，而不是发明无法对账的「坏东西」类。

### 2. D0–D4：外观缺陷与可见边界

- **D0 正常：** 约定视角与最小像素下，外形完整、位置在期望交点附近。没有 D0，很难学会「这里应该有东西」。
- **D1 缺失：** 应出现位置不见该部件。被道砟完全盖住 → 倾向 D5，不是武断 D1。
- **D2 可见断裂/裂纹：** 宏观可辨开口或断裂缝。显微裂纹、需探伤才知的缝 → **不要硬塞主类**。
- **D3 松脱/位移：** 部件还在，但姿态/位置相对期望明显偏移。协议要写参考（轨向、枕边、螺母对中等）。
- **D4 宏观腐蚀/剥落：** 大块锈蚀或表层脱落；与灰/水渍要有书面区分规则（学习阶段先有「必须有协议」意识）。

### 3. D5、忽略区与主 mAP

| | D5 | 忽略区 |
|---|---|---|
| 含义 | 看了但状态不可判定 | 协议规定本帧/本区**不参与评价** |
| 例子 | 半掩埋弹条、强阴影轮廓不清 | 列车占满画面、划定的忽略多边形 |
| 评价 | 通常不进主 mAP 或单独质量统计 | 不计入该区 TP/FP（按协议） |

二者在 Data Records 必须写清，否则会被认为「难例消失术」抬 mAP。主表建议：D1–D4（或冻结后主缺陷集）报检测指标；D0 对照；D5 单独质量统计。

### 4. 诚实巡检用语与禁止说法

**可写：** 外观可见缺失、可见裂纹、明显错位、大面积锈蚀剥落、被遮挡无法判定。  
**无引证时勿写：** 冒充国标伤损等级、未测量「紧固力矩不合格」、内部伤损断言、「需立即下道」等作业结论。告警/派发属于 **B**。

| 禁止 | 改法 |
|---|---|
| 「国标 D3=松脱」无出处 | 「项目工作码 D3；未引证国标」 |
| D5 进主 mAP 刷分 | D5 单独报或忽略规则 |
| 显微裂纹硬进 D2 | 稀缺披露或排除 |
| 脏污一律打 D4 | 先写外观区分规则 |
| 告警等级语言当标签 | 只写外观状态 |
