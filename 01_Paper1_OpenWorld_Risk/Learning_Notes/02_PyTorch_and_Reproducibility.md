# 学习笔记2：PyTorch科研能力与可复现性

## 为什么服务Paper 1

会调用`train`命令不等于能做研究。Paper 1需要你判断张量是否正确、数据是否泄漏、训练和验证模式是否切换、配置是否一致、结果是否能复现。该能力也是后续七篇论文的共同实验基础。

## 必学内容

### 1. Tensor与形状

- B/C/H/W分别表示什么；
- dtype、device和归一化范围；
- 图像、框、类别标签在批量中的组织方式；
- shape不一致为何可能不报错但产生错误结果。

任务：写出一批4张640×640 RGB图像的输入形状，并说明检测标签为何不能简单堆成固定二维数组。

### 2. Dataset与DataLoader

需要掌握：

- `__len__`和`__getitem__`；
- transform只作用于训练集还是所有集合；
- shuffle、batch、worker和collate；
- 同一视频相邻帧为什么不能随机分到训练和测试；
- 原图、增强图和裁剪图如何防止跨集合。

### 3. forward、loss与autograd

最小训练流程：

```text
model.train()
for batch:
    optimizer.zero_grad()
    prediction = model(image)
    loss = criterion(prediction, target)
    loss.backward()
    optimizer.step()
```

需要解释每一行做什么，以及验证时为什么不执行反向传播。

### 4. train与eval

掌握：

- `model.train()`与`model.eval()`；
- Dropout和BatchNorm行为差异；
- `torch.no_grad()`的作用；
- 验证集用于选择模型，测试集只用于最终评价。

### 5. optimizer与学习率

只需掌握SGD/AdamW的基本区别、学习率、weight decay、warmup和scheduler的作用。当前不进行大规模超参数搜索。

必须回答：如果方法A调了20组超参数、基线只用默认值，比较是否公平？

### 6. AMP、checkpoint与恢复

- mixed precision为何节省显存、何时可能数值不稳定；
- checkpoint至少包含模型、优化器、epoch和配置；
- best与last checkpoint的区别；
- 恢复训练和加载推理权重的区别。

### 7. 随机性与日志

每次正式运行至少记录：

- Run ID；
- Git提交或代码版本；
- 数据版本与split；
- 配置；
- 随机种子；
- 环境和硬件；
- 开始/结束时间；
- 原始指标和模型权重路径；
- 是否成功及异常。

核心结论受随机性影响时使用3个种子；早期排错可以单种子，但不能据此写最终结论。

## 最小练习

不要用项目正式数据。选择一个极小分类示例或框架自带示例：

1. 检查一个batch的shape、dtype、device和标签；
2. 写出train/val伪代码；
3. 固定seed运行两次，比较输出；
4. 保存并恢复checkpoint；
5. 故意漏掉`eval()`，观察并解释潜在问题。
