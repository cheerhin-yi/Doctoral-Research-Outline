# 学习笔记1：从基本YOLO到论文级目标检测

## 你的起点

你已经学习卷积和YOLO基本概念，因此跳过卷积定义、经典CNN历史和YOLO版本年表。现在需要建立“结构—训练—指标—错误—论文实验”的完整链。

## 为什么服务Paper 1

Paper 1所有结论都建立在可靠YOLO基线上。如果不会解释Head输出、损失、标签匹配、NMS和指标，就无法判断改进来自模型、训练设置、阈值还是数据泄漏。该笔记直接支撑已知危险检测，也是未知候选和风险告警的输入。

## 必学内容

### 1. 完整数据流

需要能够解释：

```text
Image[B,3,H,W]
→ Backbone提取多层特征
→ Neck融合不同尺度
→ Detection Head输出分类与框参数
→ 解码候选框
→ 置信度筛选与NMS
→ Boxes + Classes + Scores
```

学习任务：

- [ ] 画出一张完整结构图；
- [ ] 标出每层特征图分辨率和通道的变化；
- [ ] 解释浅层高分辨率特征为什么对小目标重要；
- [ ] 说明训练阶段和推理阶段分别在哪一步不同。

### 2. Backbone、Neck与Head

- Backbone：提取局部纹理到高级语义；
- Neck：通过多尺度融合兼顾小、中、大目标；
- Head：预测类别和位置；
- 重点不是背模块名称，而是能判断某个失败是否真由该部分造成。

必须回答：

1. 小目标消失可能发生在哪些下采样位置？
2. 只增加更深网络为什么可能不改善小目标？
3. 提高输入分辨率与修改多尺度特征的代价有何不同？

### 3. 训练目标

掌握以下直觉和最小公式：

- IoU：预测框和真值框的重叠比例；
- 分类损失：预测类别与标签的差异；
- 定位损失：框的位置和尺度误差；
- 标签匹配：决定哪些预测负责哪些真值；
- 类别不平衡：大量背景和少量危险类别会怎样影响训练。

学习输出：写一张表，列出“分类错误、漏检、重复框、定位偏差”分别可能与哪些训练环节有关。

### 4. 推理与NMS

必须理解置信度阈值和IoU阈值会同时改变Precision、Recall和每图候选数。

手工练习：给出3个重叠框、类别分数和阈值，逐步执行NMS，说明哪个框被删除以及为什么。

### 5. 评价指标

必须掌握：

\[
Precision=\frac{TP}{TP+FP},\qquad Recall=\frac{TP}{TP+FN}
\]

以及IoU、PR曲线、AP、mAP50、mAP50–95、逐类AP、尺寸分层Recall。

Paper 1优先级：

1. 危险目标Recall；
2. 固定告警预算下的危险Recall；
3. 小目标和不同高度的分层Recall；
4. mAP50–95；
5. FPS、时延、参数和显存。

不能只报告mAP50，因为它对定位质量要求较低，也可能掩盖危险类别漏检。

### 6. 铁路UAV错误分类

对每个错误至少记录：

- 目标尺寸：small/medium/large；
- 飞行高度或像素尺寸；
- 遮挡程度；
- 背景类型；
- 类别；
- 错误类型：漏检、误检、分类错、定位差、重复框；
- 是否为高风险目标。

错误分析的目的不是展示更多图，而是决定是否存在一个值得测试的最小改动。
