# 练手论文文献工作区

当前只建立结构，不预填具体文献。开始阶段2后再检索、核验和登记，不把未经精读的论文加入项目。

## 检索主题

- L1：P2和高分辨率小目标检测；
- L2：多尺度检测头、尺度重配置与P5移除；
- L3：跨尺度参数共享和轻量检测头；
- L4：真实推理延迟、ONNX/TensorRT与精度—速度折中；
- L5：使用已有标签进行遮挡分层评价。

## 使用方法

1. 先在[Literature_Matrix.md](Literature_Matrix.md)登记题录和主题；
2. 通过出版方或论文原文核验作者、年份、方法、数据和结果；
3. 精读时复制[Paper 1论文笔记模板](../../Literature/Paper_Note_Template.md)到本目录；
4. 每篇重点记录“新增了什么、是否与LSM-Head同构、用了什么公平基线、是否测真实延迟”；
5. 查新完成前，不冻结“新颖”或“首次”表述。

本目录不收开放世界、铁路风险、通信、三维、多模态、强化学习或多无人机文献。
