# 怎么用这本手册

更新：2026-09-29。阶段变了就改本节和 `00_Overview/Current_Stage.md` 的「应读」，两处保持同一清单。

本目录是查找手册和快速入门，不是课程，也不是论文笔记。论文结构、实验数字仍在各方向 `Learning_Notes/` 和 `Research_Plan.md`。

公式用 `$...$` 和 `$$...$$`。GitHub 与 Typora 都能渲染。不要改回 `\(...\)` 或 `\[...\]`，这两处阅读器不显示。

## 三层

- **必学：** 不看就读不懂公式。每条有符号、参数含义、单位或取值、一个最小例子。
- **查阅：** 只留名字、它解决什么、去哪一条翻。
- **扩展：** `11`–`14`。经典算法的最小集合，不是当前 P0 的前提。
