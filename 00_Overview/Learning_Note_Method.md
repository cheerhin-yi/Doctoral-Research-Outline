# 项目研究学习与记录统一方法

_适用于练手论文、Paper 1及以后正式启动论文的学习、文献、实验和写作记录。当前唯一任务仍以[当前阶段](Current_Stage.md)为准。_

---
## 🎯 本笔记怎么用

这不是标准答案，也不是必须从上到下填满的表格。每次只沿一段数据流学习，把新理解写到对应环节；同一问题可以先留空，后续查证后再补。

记录形式可以自由选择：

- 一段自己的话
- 几个要点
- 手写图或截图的文件链接
- 代码输出或源码位置
- 一个算例
- 一个尚未解决的问题

公式、结构图和大表格不要求反复手敲。画图时查[Mermaid画图语法指南](../99_Attachments/Mermaid_Syntax_Guide.md)；需要写公式时查[Markdown数学公式写法](../99_Attachments/Markdown_Math_Syntax_Guide.md)。
## 🎯 方法目标

本方法只解决三个问题：

1. 按什么顺序推进学习、文献、实验和写作
2. 每类笔记记录什么，避免同一内容到处重复
3. 怎样证明真正掌握，同时避免把时间耗在图、表、公式和排版上

基本原则是：

> 先形成自己的理解，再留下最小验证证据，最后只在确有用途时整理图表和公式。

笔记不是资料摘抄，也不是排版作业。是否完成由“能否复述、能否验证、能否用于研究决策”决定，而不是由篇幅、表格数量或图是否精美决定。

## 📍 总体执行顺序

一般研究任务按照以下顺序推进；2026-09-10经用户批准，练手论文主线A先做可行性审查，具体例外见下方主线A阶段顺序：

```text
学习笔记
→ 文献检索记录
→ 文献矩阵初筛
→ 单篇论文精读笔记
→ 文献综合与方法冻结
→ 最小代码复现
→ 数据集审计与冻结
→ 正式基线实验
→ 单一方法实验
→ 结果分析
→ 论文写作与投稿
```

按各论文当前有效阶段门推进；主线A允许在模型工作前先做文献与数据可行性审计。已经存在的实验计划只是边界和预案，不表示实验已经获准执行。

练手论文完成后，才继续Paper 1专属学习、文献和实验。Paper 2–7保持`PAUSED`，直到总项目规划文件明确启动。

## 📚 四类记录的职责

### 学习笔记

记录“我是否理解研究所需的基础知识”。主要内容是自己的复述、知识链、最小验证和未解决问题。

学习笔记不承担文献综述、实验结果汇总或论文写作任务。

### 文献记录与论文笔记

记录“别人已经做了什么，以及这些证据怎样影响本项目”。

- 检索日志记录查了什么、在哪里查、用了什么条件
- 文献矩阵记录候选论文、优先级、状态、主题结论和冲突风险
- 单篇论文笔记记录问题、方法、数据、对照、结果、局限及与本项目的关系

单篇笔记完成后，关键证据必须写回文献矩阵。不要把整篇论文逐段翻译或大段摘抄。

### 实验计划与实验追踪

实验计划记录“准备验证什么、怎样公平比较、何时停止”。它可以提前存在，但在阶段门禁解除前保持`BLOCKED`。

实验追踪记录“某一次运行实际上做了什么、得到什么、为何失败”。每次运行必须先登记，再执行，不能得到结果后补写条件。

### 结果分析与论文稿

结果分析只使用已经登记的运行。每个数字、图和结论必须能够回链到Run ID、配置、代码版本、数据版本和原始日志。

论文稿负责组织经过验证的主张，不负责保存原始实验事实。没有运行证据的数字不得进入论文。

## 🔗 学习笔记的知识链

每个主题按关系学习，不把概念拆成互不相连的定义：

```text
输入或前提
→ 核心机制
→ 输出
→ 怎样评价
→ 可能怎样失败
→ 对当前研究有什么影响
```

技术主题可以换成更具体的链。例如PyTorch训练链：

```text
数据
→ DataLoader
→ forward
→ loss
→ backward
→ optimizer
→ validation
→ checkpoint
```

学习每个节点时只追问：

- 它接收什么？
- 它做了什么？
- 它输出什么？
- 它与前后节点怎样连接？
- 它出错时能观察到什么？
- 它是否会改变本项目的实验或边界？

## ✅ 必须掌握的少量内容

每份学习笔记只选少量真正构成后续研究前提的掌握单元，不设固定比例，也不追求覆盖全部概念。

一个内容只有同时满足以下条件，才列入“必须掌握”：

- 不掌握就无法可靠完成下一阶段任务
- 能脱离原文，用自己的话沿知识链连续复述
- 能用指定的最小证据检查，而不是只凭“看懂了”判断
- 能说明它对当前论文实验、结论或研究边界的影响

每个掌握单元必须写清两件事：

- **复述要求**：闭卷时需要讲清什么
- **验证方式**：用什么最小证据确认已经掌握

补充知识可以沿知识链继续记录，但不进入当前阶段的完成门。

## ✍️ 低负担记录方法

### 第一层：学习时只记录理解

学习过程中优先使用自然语言、短要点和简单箭头。每次只需追加：

```text
日期／本次学习节点：

本次只学：
我的复述：
与前后节点的联系：
最小验证：
证据位置：
仍不确定：
```

不要求一次填完整份笔记，也不要求当场整理成正式图表。

### 第二层：需要时才整理表达

只有满足下列用途之一时，才把原始记录转换为图、表或规范公式：

- 图能明显帮助理解多个节点之间的关系
- 表需要比较多个方法、配置或结果
- 公式需要用于手算验证、代码核对或论文写作
- 内容即将用于阶段检查、实验方案或论文正文

具体采用以下简化方式：

- **结构图**：先写一行箭头；关系稳定后再画。可以使用手绘照片、截图或Mermaid，不强制重复绘制
- **表格**：学习时先写带名称的要点；只有需要横向比较时再整理成表
- **公式**：先记录公式名称、含义、输入、输出和一个算例；不要求重复抄写完整推导
- **源码**：只记录文件位置、关键输入输出、观察结果和它验证了什么，不复制大段代码
- **论文内容**：只记录与本项目问题直接相关的证据，不逐段翻译

画图需要查语法时使用[Mermaid画图语法指南](../99_Attachments/Mermaid_Syntax_Guide.md)，公式需要排版时使用[Markdown数学公式写法](../99_Attachments/Markdown_Math_Syntax_Guide.md)。这些都是按需工具，不是学习任务。

### 最小证据的选择

每个必会单元只需要一种合适的最小证据：

- 闭卷口述后写出的要点
- 一组手算及结果
- 一张手绘图或简单箭头链
- 一个可检查的输入输出案例
- 一段代码运行输出及环境信息
- 一个错误案例与原因判断
- 一条带页码、章节或源码位置的证据

同一知识不需要同时制作公式、表格和结构图。选择最能证明理解的一种即可。

## 🔄 单次学习任务的执行方式

每轮只处理[当前阶段](Current_Stage.md)指定的一项任务：

1. 确认本轮唯一主题、成功标准和禁止事项
2. 选择知识链中的一个连续片段
3. 阅读或观察资料，只记录与该片段有关的内容
4. 合上资料，用自己的话完成复述
5. 完成该掌握单元指定的最小验证
6. 标记证据位置和仍不确定的问题
7. 检查完成门；未通过则继续同一任务，不提前进入下一项

如果只是“看过”“听懂”或复制了标准答案，但不能闭卷复述和验证，该任务仍然未完成。

## 📋 练手论文主线A的阶段顺序

2026-09-10用户已批准调整：先可行性审查，学习按需补齐。具体门见[阶段指南](../00_Startup_Railway_UAV_Detection/Stage_Guide.md)。

A0允许许可核验后的审计下载和只读分析，不运行模型，不补造标注，不冻结训练划分。该例外只适用于当前主线A，不解除Paper 1或Paper 2–7的门禁。

学习沿检测链、切片与坐标合并、原始来源分组与泄漏、端到端测速组织。记录方式、本人复述和最小验证要求保持；S0-01仍未通过。详见[按需知识链](../00_Startup_Railway_UAV_Detection/Learning_Notes/07_Mainline_A_Knowledge_Chain.md)。

旧共享检测头学习转为历史／可选；旧阶段0–7及B0/B1/B2/M要求已退出执行，原文可查Git历史，不删除已有学习初稿。没有通过学习验收的条目不得标DONE。模型工作前仍需补足其真正依赖的知识，而非以固定笔记数量判断准备程度。

## ⚙️ 实验追踪的固定顺序

每一次代码复现或实验运行都按以下顺序执行：

1. 分配Run ID
2. 填写目的、假设和唯一变量
3. 填写代码版本、数据版本、配置、seed和硬件
4. 填写评价指标与停止条件
5. 将状态改为`READY`
6. 开始运行并改为`RUNNING`
7. 保存配置、日志、权重和原始结果
8. 根据事实标记`DONE`、`FAILED`或`EXCLUDED`
9. 写明结果位置、异常和失败原因

不能先运行再补登记，不能删除失败运行，也不能把不同训练预算或评价协议的结果放在同一公平比较中。

## 🚫 记录边界与完成门

- 同一事实只保存在职责最匹配的文件中，其他位置使用链接
- 当前任务的答案直接写入对应学习笔记，不另建每日任务说明
- 文献事实先进入单篇笔记，再把研究决策所需证据写回矩阵
- 实验原始事实进入运行记录，论文只引用Run ID和汇总结果
- 不为尚未启动的Paper 2–7创建学习、实验或写作材料
- 不为了笔记好看而重复制作图、表和公式
- 不用篇幅、阅读数量或排版完整度代替掌握和证据

### 学习任务完成门

一份学习笔记只有同时满足以下条件才算通过：

- 能沿知识链闭卷讲清主题
- 每个必会单元都完成自己的复述要求
- 每个必会单元都留下指定的最小验证证据
- 能说明适用条件、失败情况和不确定内容
- 能说明该知识怎样影响当前论文
- 所有未确认判断都明确标记为待核验

阶段是否完成以及下一项任务是什么，始终回到[当前阶段](Current_Stage.md)和[练手论文阶段指南](../00_Startup_Railway_UAV_Detection/Stage_Guide.md)确认。
