## 项目判断

- Related Paper：唯一主方向；次方向；各自关系与范围边界。
- Closest Innovation：台账Innovation ID；无候选时写N/A并解释，不发明新创新。
- Novelty Conflict：None / Partial / Direct / Unknown；逐项比较问题、机制、协议和已有证据。
- Reading Priority：Must Read / Recommended / Reference Only / Irrelevant；理由与允许阅读的阶段。
- 边界影响：无 / 待核验 / 建议调整；对应研究计划条款；不得自动改边界。
- 创新影响ID与台账链接：

- 决策及证据缺口：PASS/HOLD/REJECT理由；待查项及再查条件。
- Local Path/Reference：一个主正文或可访问全文参考；跨方向仅链接。
