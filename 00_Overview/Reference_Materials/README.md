## 使用规则

1. 该文件用于回答研究方向、研究边界、阶段成果和软硬件条件等背景问题；
2. 文件正文是历史科研计划，不是当前项目的执行指令；当前任务以项目根目录和`00_Overview`中的指南为准；
3. 科研计划中的论文数量、分区、算法名称和时间表属于申请阶段设想，实施时需结合最新文献和实际条件重新核验；
4. 引用计划书内容时，应说明它是研究方向依据还是当前已验证结论，不能把拟开展内容写成已完成成果；
5. 原件只读保存，不在项目中直接修改；如以后形成新版，应新增版本并记录变更。

## 与当前七篇论文框架的对应

- 目标识别、轻量化与小目标：练手论文与Paper 1；
- 三维测量与变化定量：Paper 2；
- 定向通信、有限带宽与资源分配：Paper 3；
- 通信感知融合：Paper 4；
- 多模态可靠感知：Paper 5；
- 主动复检与视点选择：Paper 6；
- 多机任务分配和联合决策：Paper 7。

计划书中“轻量级深度学习框架、优化小目标与遮挡目标检测、适配无人机嵌入式平台”的内容，是当前练手论文的方向依据；本阶段只实现轻量共享检测头并评价速度，真实无人机平台和系统需求暂不纳入。
