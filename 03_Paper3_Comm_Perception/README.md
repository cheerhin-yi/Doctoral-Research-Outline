# Paper 3：通信受限多无人机协同风险感知

**状态**：PAUSED；Paper 1风险语义稳定前不学习通信专题、不实验。

## 要回答的问题

有限带宽、时延和动态信道下，无人机应该传原图、特征、目标、风险，还是只传最重要的少量信息？

## 预期输入与输出

- 输入：Paper 1风险、未知程度、可信度和候选区域；链路状态与任务预算；
- 输出：信息重要性、语义粒度、传输策略和协同感知性能。

## 启动后需要学习

1. SNR/SINR、容量、时延、丢包和可靠性；
2. 无线信道、OFDM、MIMO和CSI最低知识；
3. 任务导向语义通信；
4. 优化问题中的变量、目标和约束；
5. 通信代价与感知任务性能的联合评价。

## Paper 1怎样帮助

Paper 1定义“什么信息有任务价值”：高风险目标、未知候选、轨道关系和不确定性。没有这些字段，Paper 3只能做一般图像压缩，无法体现风险驱动通信。

## 启动门槛

- Paper 1风险语义和评价指标稳定；
- 已完成通信受限协同感知最近工作审计；
- 能建立一个可验证的简化链路模型；
